# 설계 결정 번호 301~350

## D-301 정책 정의와 집행 증거를 분리해 조회한다 (2026-10-31)

- 이유: 관리대장에 운영으로 등록된 정책과 실제 실행 경로에서 집행되는 정책은 같은 사실이 아니다. 원본 오류 시 이전 캐시로 목록을 만들면 현재 로드 상태를 오해할 수 있다.
- 결정: 관리대장 API는 현재 OPA 문서를 직접 조회하고 조회 상태와 시각, 실행 규칙과 정책 데이터의 배포 대조, 최근 24시간 최종 판정 집계를 반환한다. 조직 단위 원장 집계가 추가되므로 관리자 인증을 요구한다. 집행 자체와 원장은 변경하지 않는다.
- 화면: 정책 목록의 집행 주체, 관리 상태, 정의된 결과, 원장 근거, 관련 POL을 분리한다. 상세에는 정의와 집행 근거 및 명시적 연결을 두며 감사 화면으로 이동한다. 서버 권한과 호출 원문을 중복 표시하지 않는다.
- 경계: 배포 해시 일치와 원장 기록은 현재 집행 경로 및 독립 효과의 검증이 아니다. pol_ids가 없는 정책은 POL 연결 미확인이다. 정책 충돌에서 선택되지 않은 규칙과 무효 표시된 기록의 유효성 판정은 집계에 포함하지 않으며, 집계는 최종 policy_id 원장 행 수만 의미한다.
- 검증: UI 93개, 격리 API 시험 6개 및 인증과 제품 문구 정적 검사. 실제 OPA 및 DB 연동, 솔루션 배포와 브라우저 검수는 미실행이다.
- 보고: research/llm-wiki/status/reports/2026-10-31-policy-evidence-ui.md

## D-302 조직 보안 정책 카탈로그는 실행 정책 및 적용 증거와 분리한다 (2026-10-31)

- 이유: 조직의 POL 전체 목록은 구현 규칙 목록과 다른 정보다. 별도 PaC 코드의 존재를 현재 게이트웨이에서 적용 중이라는 표시로 바꾸면 안 된다.
- 결정: 정책 원본과 구현 분류 및 Rego 판정 줄과 시험 정의에서 읽기 전용 제품 카탈로그를 재생성한다. 제품 이미지의 앱 디렉터리에 포함하고 기존 관리자 정책 API로만 제공한다. 원본이 없거나 잘못되면 조회 실패로 구분한다.
- 화면: 조직 보안 정책과 집행 규칙을 나눈다. 조직 정책은 대상, 적용 단계, 구현 방식, 코드 확인과 조직 적용 확인을 표시한다. 상세에는 본문과 통과 및 차단 요건, 시험 정의와 집행 규칙 검토 후보를 둔다.
- 경계: 과거 정적 분류의 구현 상태를 현재 적용 상태로 쓰지 않는다. 규칙 및 시험 정의는 실행 성공을 의미하지 않는다. 정적 검토의 후보 ID가 현재 관리대장에 있더라도 검토된 POL 매핑으로 승격하지 않는다. 원문 지시는 분석 데이터다.
- 검증: 원본 일치와 누락 및 손상된 카탈로그, 규칙 정의 추적 및 화면 이스케이프와 미확인 상태 시험. 기기 배포와 브라우저 검수는 미실행이다.
- 보고: research/llm-wiki/status/reports/2026-10-31-organization-policy-tab.md

## D-303 승인 작업은 처리 대상의 화면으로 이동한다 (2026-10-31)

- 이유: 단독 승인 대기 화면은 호출 승인, 실행 확인, 개인 이용 동의처럼 처리 주체와 목적이 다른 작업을 한곳에 섞는다.
- 결정: 호출 승인은 대시보드의 요약과 전체 목록 탭으로 옮긴다. 실행 확인과 승인 처리 이력은 호출 및 감사 기록으로 옮기고 본인의 이용 동의는 내 계정 메뉴 그룹에 둔다. 가입 승인과 엔드포인트 활성화 및 도입 신청은 기존 관리 화면에서 처리한다. 기존 승인 대기 주소는 새 화면으로 연결한다.
- 경계: 승인, 거부, 증빙 확인, 본인 요청 제한, 승인 번복 및 실행 확인 API는 유지한다. 개인 이용 동의를 관리자 대행 기능으로 확장하지 않는다. 감사 원장과 판정 규칙은 바꾸지 않는다.
- 검증: 메뉴 구성과 이전 주소 이동, 요약 5건과 전체 목록, 본인 요청 버튼 제한, 실행 확인 및 번복 버튼, 번역과 중대 영향 증빙 표시 관련 로컬 테스트 30개 통과. 실기기 배포와 브라우저 검수는 미실행이다.
- 보고: research/llm-wiki/status/reports/2026-10-31-approval-ui-relocation.md

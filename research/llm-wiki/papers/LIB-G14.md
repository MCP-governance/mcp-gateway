# LIB-G14 · A Large-Scale Evolvable Dataset for Model Context Protocol Ecosystem and Security Analysis

약 1만 4천 개 MCP 서버와 300개 클라이언트를 20개 이상의 정규화 속성으로 정리한 재현 가능한 데이터셋 MCPCorpus를 공개한다. 자동 동기화, 정규화, 검사 도구와 간단한 웹 검색 인터페이스도 함께 제공한다.

## 출처와 확인 수준

- 공식 출처: [A Large-Scale Evolvable Dataset for Model Context Protocol Ecosystem and Security Analysis](https://arxiv.org/abs/2506.23474)
- 유형: 데이터셋 · 2025년 · arXiv preprint · `preprint`
- 저자·발행: Zhiwei Lin, Bonan Ruan, Jiahao Liu, Weibo Zhao
- 확인일: 2026-10-14 / `arxiv_abs_title_matched` — 제목·저자·최초 게시 연도를 공식 페이지와 대조했다.
- 요약 검토: 초록과 문장 단위로 대조했다.
- 배포: `public-under-license` — 서지와 자체 요약만 보관하고 원문은 복제하지 않는다.

## 읽은 내용

- 약 14K 서버와 300 클라이언트 규모의 스냅샷을 제공한다.
- 각 항목에 20개 이상의 정규화 속성(정체성, 인터페이스 설정, GitHub 활동, 메타데이터)을 붙였다.
- 동기화, 정규화, 검사 도구를 GitHub에 공개했다고 밝힌다.

## 우리 솔루션 개발에 사용할 곳

- 게이트웨이의 계약(스키마) 변경 탐지와 회귀 테스트에 실제 도구 정의 샘플을 공급한다.
- 서버 등록 심사 기준(인증 방식, 유지보수 속성 등)의 통계 베이스라인으로 쓴다.
- 라이선스가 CC BY-NC-ND 4.0이므로 재배포와 상업적 사용 범위를 확인한 뒤 사용한다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

## 한계와 사용 조건

WebFetch로 확인한 초록 수준만 반영했다. 데이터셋 자체와 공개 저장소는 직접 열어 확인하지 않았다. 스냅샷 시점이 2025년 중반이라 오래되었을 수 있다. 전문은 미정독이다. 요약 초안은 조사 에이전트가 작성했고 위 검토 수준까지 확인했다. 발행처 표기는 확인하지 않았다.

# LIB-I04 · OWASP Top 10 for LLM Applications 2025

LLM 및 생성형 AI 앱에서 중요한 위험 10개와 완화책을 정리한 OWASP 목록의 2025판이다. 1순위인 프롬프트 인젝션과 과도한 권한(LLM06) 등을 포함한다.

## 출처와 확인 수준

- 공식 출처: [OWASP Top 10 for LLM Applications 2025](https://genai.owasp.org/llm-top-10/)
- 유형: 보고서·권고 · 2025년 · OWASP GenAI Security Project · `official_publication`
- 저자·발행: OWASP GenAI Security Project
- 확인일: 2026-10-14 / `page_title_matched` — 제목을 공식 페이지와 대조했다.
- 요약 검토: 출처 페이지와 수치·용어를 대조하고 의심 문장은 원문으로 확인했다.
- 배포: `public-under-license` — 서지와 자체 요약만 보관하고 원문은 복제하지 않는다.

## 읽은 내용

- 10개 항목은 LLM01 프롬프트 인젝션부터 LLM10 무제한 소비까지이며, 프롬프트 인젝션이 1순위다.
- 과도한 권한(LLM06)을 별도 항목으로 둬, 도구 권한 설계를 독립된 위험으로 다룬다.

## 우리 솔루션 개발에 사용할 곳

- LLM01(프롬프트 인젝션)과 LLM06(과도한 권한)을 게이트웨이 정책 설계의 기준 항목으로 쓴다. 도구 호출 전 OPA 정책으로 권한 범위를 좁히고, 도구 응답 안의 지시문이 호출 인자를 바꾸지 못하게 한다.
- LLM02(민감 정보 노출)와 LLM05(부적절한 출력 처리)를 응답 측 PII 마스킹과 출력 검증 규칙의 근거로 쓴다.
- LLM03(공급망)과 LLM04(데이터·모델 포이즈닝)를 MCP 서버 목록 관리와 계약(스키마) 변경 탐지의 근거로 연결한다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

# P47 · Real Faults in MCP Software: A Comprehensive Taxonomy

실제 MCP 서버의 결함을 조사한 taxonomy 연구다. 프롬프트 공격뿐 아니라 응답 검증·설정·경계·재현 가능 오류 보고를 개발 회귀 검사에 포함하는 자료다.

- 이전 위키 검증 표기: `metadata`
- 판본·입수 이력: [provenance](../sources/policy/P47/upstream.json)

## 읽은 내용

- 실제 소프트웨어 결함을 높은 수준의 범주로 묶어 조사한다.
- MCP 특수 결함과 일반 소프트웨어 결함의 구분을 검토한다.
- 관찰 범위와 조사 방식이 있어 생태계 전체 결함률로 일반화할 수 없다.

## 우리 솔루션 개발에 사용할 곳

- 잘못된 스키마·빈 결과·이상 응답·전송 종료·설정 누락을 회귀 사례로 만든다.
- 결함 보고에 서버·SDK·전송·입력·원장·upstream 효과를 포함한다.
- 보안 차단과 기능 장애를 동일 성공 값으로 처리하지 않는다.

## 우선 읽을 절

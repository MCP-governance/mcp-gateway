# P64 · SafeHarness: Lifecycle-Integrated Security Architecture for LLM-based Agent Deployment

SafeHarness는 입력·의사결정·행동·상태 갱신 단계의 방어를 수명주기에 통합하는 구조다. Gateway가 볼 수 없는 하네스 내부 상태와 rollback의 경계를 확인하는 개발 자료다.

## 출처와 확인 수준

- 공식 출처: [SafeHarness: Lifecycle-Integrated Security Architecture for LLM-based Agent Deployment](https://arxiv.org/abs/2604.13630v2)
- 확인일: 2026-10-13 / `local_sha256_checked_and_selected_extract_read`
- 원본 배포: `public-under-license` / 보존 판본의 CC BY 4.0 허용을 공식 출처에서 확인했다. 저자·제목·출처·원본 라이선스와 기계 추출 표시를 유지한다.
- 이전 위키 검증 표기: `metadata`
- 판본·입수 이력: [provenance](../sources/policy/P64/upstream.json)

## 읽은 내용

- 입력 필터·인과 검증·권한 분리 도구 제어·상태 rollback을 층으로 연결한다.
- 상태 이상이 지속될 때 검증 강도·도구 권한·퇴행 동작이 바뀐다.
- 하네스 내부 통합이 필요한 기능은 외부 Gateway만으로 자동 확보되지 않는다.

## 우리 솔루션 개발에 사용할 곳

- 지원 하네스에 직접 훅이 필요한 통제와 MCP 프록시로 가능한 통제를 분리한다.
- 상태 rollback과 이미 실행된 외부 부작용의 원복을 따로 검증한다.
- 모델·하네스·상태 저장소 버전과 격리 수준을 실험 기록에 포함한다.

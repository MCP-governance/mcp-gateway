# T12 · RFC 9396: OAuth 2.0 Rich Authorization Requests

단순 scope 문자열보다 상세한 자원·행위·데이터 유형의 권한을 authorization_details로 요청하는 규격이다. 사용자 승인 내용을 실제 호출 인자와 결합하는 설계에 사용한다.

## 읽은 내용

- type·locations·actions·datatypes 등의 구조로 권한의 세부 범위를 표현할 수 있다.
- scope와 authorization_details의 조합 및 요청·부여 권한의 차이를 명시한다.
- 인가 서버가 부여 권한을 자원 서버에 전달해야 실제 집행이 가능하다.

- 요청한 권한보다 실제 부여된 권한을 기준으로 호출을 판정한다.
- 알 수 없는 type·field·값과 승인 요청 변조의 실패 조건을 검사한다.

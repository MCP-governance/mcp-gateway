# LIB-I01 · OWASP Top 10 for Agentic Applications 2026

자율적으로 계획하고 행동하며 여러 단계 워크플로를 수행하는 에이전트 시스템의 가장 중요한 보안 위험을 정리한 OWASP 목록이다. 2025년 12월 9일 공개되었고, 동료 검토를 거쳤다고 밝힌다.

## 출처와 확인 수준

- 공식 출처: [OWASP Top 10 for Agentic Applications 2026](https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026)
- 유형: 보고서·권고 · 2025년 · OWASP GenAI Security Project · `official_publication`
- 저자·발행: OWASP GenAI Security Project (100명 이상 실무자 참여, 개인 저자 미표기)
- 확인일: 2026-10-14 / `page_title_matched` — 제목을 공식 페이지와 대조했다.
- 요약 검토: 출처 페이지와 수치·용어를 대조하고 의심 문장은 원문으로 확인했다.
- 배포: `public-under-license` — 서지와 자체 요약만 보관하고 원문은 복제하지 않는다.

## 읽은 내용

- 공개 주체는 OWASP GenAI 보안 프로젝트이며, 범위는 자율 에이전트 시스템이다(랜딩 페이지 기준).
- 랜딩 페이지에는 10개 항목의 목록과 명칭이 없고 PDF 다운로드로만 제공된다. 따라서 항목 명칭은 이 조사에서 검증하지 못했다.

## 우리 솔루션 개발에 사용할 곳

- 게이트웨이 위협 모델링의 기본 목록으로 쓰고, 항목별로 게이트웨이의 통제 지점(도구 호출 정책, 승인, 감사 원장, 계약 변경 탐지)을 대응시킨다. 항목명은 PDF 확인 후 매핑한다.
- 에이전트가 쓰는 자격증명과 도구 범위를 항목별로 점검하는 체크리스트를 만들어 배포 전 점검 항목에 넣는다.
- 이 목록을 OWASP LLM Top 10(2025)과 함께 대조해, 에이전트 고유 위험(도구 호출 체인, 권한 연쇄)이 빠지지 않았는지 확인한다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

## 한계와 사용 조건

랜딩 페이지 본문만 읽음. PDF 본문, 항목별 설명, 버전 번호는 미정독·미확인. 검색 결과의 2차 블로그 항목명(ASI01~ASI10)은 검증하지 않았으므로 인용하지 말 것. 요약 초안은 조사 에이전트가 작성했고 위 검토 수준까지 확인했다. 발행처 표기는 확인하지 않았다.

라이선스 미확인: 본문을 복제하지 않고 서지·자체 요약만 보관한다.

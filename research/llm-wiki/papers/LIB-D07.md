# LIB-D07 · MiniScope: Authorizing Agents with Least-Privilege Permissions

LLM이 사용자 계정에서 도구를 쓸 때 모델 오작동으로 생기는 피해를 줄이기 위해, 도구 호출 사이의 관계에서 권한 계층을 자동으로 재구성하고 모바일식 권한 모델로 최소 권한을 집행하는 MiniScope를 제안한다. 도구 호출마다 승인을 묻는 방식 대신 과제 단위 역할로 에이전트를 다룬다.

- 저자·발행: Jinhao Zhu, Xiao Huang, Kevin Tseng, Gil Vernik 외

- 요약 검토: 초록과 문장 단위로 대조했다.
- 배포: `public-under-license` — 서지와 자체 요약만 보관하고 원문은 복제하지 않는다.

## 읽은 내용

- 도구 호출마다 승인을 묻는 방식은 승인 피로를 낳고, 과제 단위 권한 계층이 이를 줄인다고 주장한다(최신판 초록).
- 시뮬레이션 기반 권한 확인 횟수가 사용자 유형에 따라 43.4-89.4% 줄었다고 보고한다(최신판 초록).
- 최신판 초록은 권한 확인을 사용자 유형에 따라 43.4~89.4% 줄이고 상승 공격은 모두 막았다고 보고한다. 실제 ChatGPT·Claude 커넥터 설정에서 과권한 사례 6건을 찾았다고도 한다.

## 우리 솔루션 개발에 사용할 곳

- 커넥터 권한을 도구 단위가 아니라 과제 단위 권한 계층으로 묶는 정책 모델을 OAuth 스코프 매핑 설계에 참고하고, 현재 스코프가 과도하게 넓은지 점검한다.
- 최신판이 ChatGPT와 Claude의 커넥터 구성에서 과권한 사례를 찾았다고 밝혀, MCP 서버 등록 시 과권한 점검 항목의 근거로 쓴다.
- 권한 상승 공격 시나리오를 게이트웨이 정책 회귀 테스트 케이스로 옮긴다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

## 한계와 사용 조건

초록과 프로젝트 소개만 확인했고 전문은 정독하지 못했다. 평가가 합성 데이터셋 기반이라 실제 사용자 과제로의 일반화는 확인되지 않았다. v1과 최신판의 제목과 결과 서술이 다르므로 인용 시 버전을 명시해야 한다. 요약 초안은 조사 에이전트가 작성했고 위 검토 수준까지 확인했다. 발행처 표기는 확인하지 않았다.

라이선스 미확인: 본문을 복제하지 않고 서지·자체 요약만 보관한다.

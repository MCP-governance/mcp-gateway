# LIB-J12 · SLSA specification (v1.0)

소프트웨어 공급망 보안을 점진적으로 높이기 위한 산업 합의 명세로, 보안 수준, 아티팩트 생성과 배포와 검증 절차, 빌드 플랫폼 검증, 위협과 완화책을 정의한다. provenance와 verification summary 같은 attestation 형식도 포함한다.

## 출처와 확인 수준

- 공식 출처: [SLSA specification (v1.0)](https://slsa.dev/spec/v1.0/)
- 유형: 명세·제안 · 2023년 · SLSA 명세 v1.0 (페이지는 v1.2를 현재 버전으로 표기) · `official_publication`
- 저자·발행: SLSA 커뮤니티 (명세 페이지에 개별 저자 표기 없음)
- 확인일: 2026-10-14 / `page_title_matched` — 제목을 공식 페이지와 대조했다.
- 요약 검토: 출처 페이지와 수치·용어를 대조하고 의심 문장은 원문으로 확인했다.
- 배포: `public-under-license` — 서지와 자체 요약만 보관하고 원문은 복제하지 않는다.

## 읽은 내용

- 명세 목표는 공급망 보안을 설명하고 점진적으로 개선하기 위한 산업 합의 명세라고 페이지가 밝힌다(페이지 확인).
- 목차에 위협과 완화책, 빌드 플랫폼 검증, provenance와 verification summary 형식이 있다(페이지 확인).

## 우리 솔루션 개발에 사용할 곳

- MCP 서버 배포 파이프라인을 SLSA 수준으로 단계화하고, 게이트웨이 정책에 '최소 수준 이상의 provenance가 있어야 설치 허용'을 규칙으로 넣는다.
- verification summary 형식을 게이트웨이 승인 기록의 한 형태로 맞추면 외부 감사에 증거를 제출하기 쉽다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

## 한계와 사용 조건

명세 목차와 목표 문구만 확인했고 개별 요건은 정독하지 않았다. 페이지가 v1.0을 표기하지만 최신 버전은 v1.2로 표시되어 기준 버전을 확인해야 한다. 발행 연도는 페이지에 없어 2023은 추정치이다. 요약 초안은 조사 에이전트가 작성했고 위 검토 수준까지 확인했다. 발행처 표기는 확인하지 않았다.

라이선스 미확인: 본문을 복제하지 않고 서지·자체 요약만 보관한다.

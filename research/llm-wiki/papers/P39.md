# P39 · AgentDojo: A Dynamic Environment to Evaluate Prompt Injection Attacks and Defenses for LLM Agents

AgentDojo는 정상 업무와 공격자 목표를 함께 평가하는 확장형 환경이다. 방어가 공격을 막는 동안 업무를 과도하게 중단하지 않는지 측정할 실험 구조로 사용한다.

- 이전 위키 검증 표기: `metadata`
- 판본·입수 이력: [provenance](../sources/policy/P39/upstream.json)

## 읽은 내용

- 상태를 가진 도구 환경에서 사용자 작업과 공격 작업을 별도로 정의한다.
- 정상 업무 실패와 공격 실패를 혼동하지 않는 지표가 필요하다.
- 새 모델·공격·방어를 연결할 수 있는 환경이지 모든 실제 업무를 대표하지는 않는다.

## 우리 솔루션 개발에 사용할 곳

- 동일한 데이터 스냅숏에서 무방어·Gateway·추가 통제의 비교군을 만든다.
- 공격 성공률과 정상 업무 성공률 및 비용·지연을 함께 기록한다.
- 테스트마다 환경을 초기화하고 부작용을 확인해 교차 오염을 막는다.

## 우선 읽을 절

- task suites and security properties
- attack and defense evaluation

# LIB-C01 · Indirect Prompt Injections: Are Firewalls All You Need, or Stronger Benchmarks?

에이전트와 도구 사이에 도구 입력을 줄이는 방화벽과 도구 출력을 정화하는 방화벽, 두 필터를 두는 모델 독립적 방어를 제안한다. 저자들은 이 단순한 구조만으로 공개 벤치마크 4종에서 간접 주입을 막을 수 있으며, 기존 에이전트 보안 벤치마크의 지표와 구현에 결함이 많다고 주장한다.

## 읽은 내용

- 저자들은 두 방화벽 조합이 네 개 공개 벤치마크에서 과제 성능을 유지하면서 간접 주입을 막는다고 보고한다(초록 기준).
- 기존 에이전트 보안 벤치마크가 단순한 방어로도 포화되며, 지표와 구현 결함이 있다고 주장한다.
- 그래서 적응형 공격과 다단계 공격 전략을 포함한 더 강한 평가가 필요하다고 제안한다.

## 우리 솔루션 개발에 사용할 곳

- 게이트웨이의 tools/call 요청 직전(입력 최소화)과 응답 직후(출력 정화)에 두 단계 필터를 두는 구조를 그대로 매핑할 수 있다. 출력 정화를 OPA 정책 판정 이전 단계에 배치하는 설계 근거가 된다.
- 논문이 지적한 벤치마크 약점(지표, 구현 버그, 약한 공격)을 평가 하네스 체크리스트에 가져와, 방어 통과 여부를 포화된 벤치마크가 아니라 적응형 공격으로 판정하도록 한다.
- 입력 최소화 필터가 정상 작업을 얼마나 깨뜨리는지 유틸리티 지표를 함께 기록하도록 릴리스 리포트 항목에 넣는다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

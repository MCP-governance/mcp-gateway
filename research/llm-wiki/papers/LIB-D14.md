# LIB-D14 · Contextual Agent Security: A Policy for Every Purpose

정적 정책이나 사용자 반복 확인으로는 범용 에이전트를 감당하기 어렵다고 보고, 과제와 맥락에 맞춰 즉석에서 생성되며 사람이 검증할 수 있는 보안 정책 Conseca를 제안한다. 정책에 명시되지 않은 행동은 모두 차단하는 방식이다.

## 출처와 확인 수준

- 공식 출처: [Contextual Agent Security: A Policy for Every Purpose](https://arxiv.org/abs/2501.17070)
- 유형: preprint · 2025년 · arXiv preprint (v1 2025-01-28) · `preprint`
- 저자·발행: Lillian Tsai, Eugene Bagdasarian
- 확인일: 2026-10-14 / `arxiv_abs_title_matched` — 제목·저자·최초 게시 연도를 공식 페이지와 대조했다.
- 요약 검토: 초록과 문장 단위로 대조했다.
- 배포: `public-under-license` — 서지와 자체 요약만 보관하고 원문은 복제하지 않는다.

## 읽은 내용

- 맥락에 맞춘 정책을 실행 시점에 생성하고, 사람이 검증할 수 있는 형태로 만든다는 점을 핵심으로 제시한다.
- 스마트폰 권한이나 네트워크 ACL처럼 수작업 정책과 사용자 확인에 기대는 방식은 범용 에이전트의 맥락 규모를 감당하지 못한다고 주장한다.

## 우리 솔루션 개발에 사용할 곳

- 과제별로 허용 도구와 인자 범위를 자동 생성해 OPA 입력 데이터로 넣는 과제 단위 정책 번들 구조를 참고한다. 생성된 정책은 사람이 검토한 뒤 활성화한다.
- 정책 생성 입력에서 신뢰된 맥락만 쓰고 이메일 같은 비신뢰 콘텐츠는 제외하는 원칙을 정책 생성 파이프라인에 적용한다.
- 정책 위반 거부 사유를 감사 가능한 형식으로 남기는 방식을 게이트웨이 감사 원장 형식에 참고한다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

## 한계와 사용 조건

초록만 확인했고 전문은 정독하지 못했다. 평가 결과를 확인하지 못했다. 정책 생성에 쓴 모델 등 세부 사항은 제3자 요약에서만 확인되어 원문 대조가 필요하다. 같은 논문이 'Context is Key for Agent Security'라는 제목으로 소개된 곳이 있다. 요약 초안은 조사 에이전트가 작성했고 위 검토 수준까지 확인했다. 발행처 표기는 확인하지 않았다.

라이선스 미확인: 본문을 복제하지 않고 서지·자체 요약만 보관한다.

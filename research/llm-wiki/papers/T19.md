# T19 · RFC 7009: OAuth 2.0 Token Revocation

RFC 7009는 OAuth 토큰 회수 엔드포인트와 응답 의미를 정의한다. 회수 요청의 성공 응답과 실제 자원 서버의 사용 불가 상태를 구분하는 종료 판정 근거다.

## 출처와 확인 수준

- 이전 위키 검증 표기: `fulltext`
- 판본·입수 이력: [provenance](../sources/policy/T19/upstream.json)

## 읽은 내용

- 회수 엔드포인트는 토큰을 무효화하고 연관 토큰을 다룰 수 있다.
- 이미 무효한 토큰도 성공 응답을 받으므로 200만으로 회수 효과를 증명할 수 없다.
- 전파 지연·503 오류와 자체 완결 토큰의 집행 한계가 남는다.

## 우리 솔루션 개발에 사용할 곳

- 회수 응답·재사용 차단·자원 서버 효과를 각각 원장에 남긴다.
- 회수 중 503일 때 완료 상태를 부여하지 않고 재시도 정책을 명시한다.
- 현재 토큰 설계의 만료·블랙리스트·검증 캐시를 대조한다.

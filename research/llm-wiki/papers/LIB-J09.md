# LIB-J09 · A Taxonomy of Runtime Faults in Model Context Protocol Servers

473개 활성 MCP 서버 저장소에서 확인된 결함 스레드 833건을 수작업으로 코딩해 MCP 서버의 런타임 결함 분류 체계를 만들었다고 보고한다. 상위 11개 범주, 하위 27개, 리프 73개로 구성되며, 서버 개발자 55명 설문에서 응답자들은 하위 범주 평균 20개를 실제로 겪었다고 답했다.

## 읽은 내용

- 확정 결함 스레드 833건, 저장소 473개, 분류 11개 범주, 27개 하위, 73개 리프, 개발자 설문 55명이라는 규모를 초록에서 확인했다.
- 설문 응답자들은 27개 하위 범주 중 평균 20개를 실제로 겪었다고 답했다.

## 우리 솔루션 개발에 사용할 곳

- 게이트웨이의 결함 주입 시험 계획에 이 분류의 범주를 가져와 세션 수명, 전송 계층, 스키마 호환성, 취소 처리 같은 시나리오를 만든다. 범주명은 본문을 확인한 뒤 확정한다.
- 스키마 변경 탐지 기능의 시험 근거로, 계약 호환성 결함이 실제 서버에서 반복된다는 점을 인용한다. 이 근거는 본문 확인 후 사용한다.
- 설문에서 관찰된 결함 범위를 게이트웨이가 방어해야 할 범위의 기준선으로 쓴다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

## 한계와 사용 조건

초록 수준만 확인했고 본문은 정독하지 않았다. 다른 목록에서는 837건으로 표기된 경우가 있어 버전별 수치 차이를 확인해야 한다. v1과 v2 사이 수치 변경 여부는 확인하지 못했다. 요약 초안은 조사 에이전트가 작성했고 위 검토 수준까지 확인했다. 발행처 표기는 확인하지 않았다.

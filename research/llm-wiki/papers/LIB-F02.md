# LIB-F02 · Enforcing Temporal Constraints for LLM Agents

인증 전 데이터 접근 금지나 승인 전 환불 금지처럼 행동 순서에 관한 제약을 전용 언어로 쓰고 1차 논리로 번역해, 토큰 생성 중 위반 도구 호출을 SMT 솔버로 막는 Agent-C를 제안한다. 소매 고객지원과 항공권 예약 두 영역에서 평가했다.

## 읽은 내용

- 기존 가드레일은 행동 순서 정책을 안정적으로 집행하지 못한다는 문제를 제기한다.
- 두 영역 평가에서 준수율이 100%로 올랐고 과제 효용도 개선됐다고 보고한다(저자 자체 평가).
- 시간 제약을 전용 언어로 쓰고 1차 논리로 옮기는 파이프라인을 제시한다.

## 우리 솔루션 개발에 사용할 곳

- 게이트웨이 정책 중 순서 규칙(예: 승인 전 쓰기 금지, 인증 후 개인정보 조회)을 세션 상태 기반 검사로 구현할 때 요구사항 목록으로 쓴다. 단일 호출을 판정하는 OPA만으로는 잡기 어려운 규칙이다.
- 위반 호출에 준수하는 대안 행동을 함께 제시하는 방식을 참고해, 게이트웨이 차단 응답에 허용되는 다음 단계 힌트를 담는다.
- 토큰 단위 제약은 하네스의 디코딩에 개입해야 하므로 외부 게이트웨이에서는 그대로 구현할 수 없다. 호출 이력 기반 상태 검사로 근사하는 것이 현실적이라고 판단한다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

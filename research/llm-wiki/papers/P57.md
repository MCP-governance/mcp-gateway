# P57 · Securing AI Agents with Information-Flow Control

FIDES는 기밀성·무결성 라벨과 동적 정보 흐름 추적으로 에이전트 행동을 제한한다. 단일 호출의 정적 분류를 넘어 여러 호출 사이 데이터 계보를 연결하는 개발 연구 자료다.

- 공식 출처: [Securing AI Agents with Information-Flow Control](https://arxiv.org/abs/2505.23643v2)
- 확인일: 2026-10-13 / `local_sha256_checked_and_selected_extract_read`

- 이전 위키 검증 표기: `metadata`
- 판본·입수 이력: [provenance](../sources/policy/P57/upstream.json)

## 읽은 내용

- 입력 데이터의 출처·기밀성·무결성이 후속 행동 결정에 영향을 준다.
- 플래너가 라벨을 추적하며 정책 집행을 결정론적으로 수행한다.
- 정보를 숨기거나 공개하는 명시 연산과 업무 표현력의 절충이 있다.

## 우리 솔루션 개발에 사용할 곳

- 읽은 민감 데이터와 외부 전송 호출을 trace·resource로 연결하는 후보를 검토한다.
- Gateway 밖 문맥과 로컬 변환이 라벨 추적에서 누락되는 경계를 표시한다.
- 낮은 무결성 콘텐츠가 목적지·도구 선택을 바꾸는 실험을 만든다.

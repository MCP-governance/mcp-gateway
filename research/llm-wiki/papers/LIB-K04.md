# LIB-K04 · Open Policy Agent — Agent Tool Calling (사용 사례 문서)

LLM의 도구 호출을 정책 결정점(OPA)에 보내 허용 여부를 정하는 흐름을 설명한다. 하네스가 집행점(PEP), OPA가 결정점(PDP)이며, 예제 정책은 금지 도구·HTTPS가 아닌 URL·결과 수 상한·도구 시간 상한을 deny 사유 집합으로 돌려준다.

## 읽은 내용

- 도구 호출은 구조화된 데이터라 허용 도구와 안전한 인자를 규칙으로 쓰기 좋다고 문서가 설명한다. 하네스가 도구 호출을 OPA에 입력으로 보내고, deny 사유 집합이 비어 있으면 실행하고 사유가 있으면 실행하지 않는다.
- 예제 정책은 Bash·Write·Edit 도구 금지, WebFetch의 비HTTPS URL 거부, WebSearch 결과 수 10 초과 거부, 도구 timeout 10초 초과 거부를 담는다.
- 하네스는 거부 사유를 LLM에 돌려줘 다음 호출을 개선하게 할 수도, 보안상 숨길 수도 있으며 선택은 사용 사례에 달렸다고 적는다.

## 우리 솔루션 개발에 사용할 곳

- **POL-16**: 원격 호출 URL의 스킴을 규칙으로 검사해 평문(http://) 전송 구성을 결정 단계에서 거부하는 패턴의 비교 대상으로 쓴다.
- **POL-28·POL-35**: 도구 인자의 결과 수·시간 상한을 deny 규칙으로 두고, 상한 없는 호출은 거부하는 방식을 우리 입력 스키마의 반환량 한도(DEV-41) 설계와 비교한다.
- **POL-22**: deny 사유 집합을 기본값 '비어 있을 때만 허용'으로 쓰는 구조가 '판단 정보가 없으면 차단'과 같은 방향인지 우리 결정 계약과 대조한다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다. 이 자료를 읽었다는 사실이 해당 정책의 구현·검수 완료를 뜻하지 않는다.

## 한계와 사용 조건

페이지 본문 앞부분(흐름·예제 정책)만 읽었다. 예제는 문서용 장난감 정책이며 우리 게이트웨이 입력 스키마와 다르다. 대응 코드를 만들거나 실행하지 않았다.

OPA 저장소 LICENSE는 Apache License 2.0이다. 문서 페이지 자체의 별도 이용 조건은 확인하지 않았다. 본문을 복제하지 않고 서지·자체 요약만 보관한다.

# T10 · RFC 9700 / BCP 240: Best Current Practice for OAuth 2.0 Security

OAuth 2.0의 보안 BCP 원문을 새로 확보했다. 코드 교환·토큰 재사용·최소 권한·refresh rotation·TLS 종료 프록시의 조건을 인증 구현 점검에 사용한다.

## 읽은 내용

- 인가 코드 흐름의 PKCE·정확한 redirect URI·issuer 결합을 함께 다룬다.
- 토큰의 대상·자원·행위 권한을 제한하며 refresh 토큰의 재사용 탐지와 회전을 다룬다.
- TLS 종료 프록시가 신뢰한 헤더와 자격정보를 안전하게 전달하도록 별도 경계를 요구한다.

## 우리 솔루션 개발에 사용할 곳

- refresh helper의 잠금·회전·재사용 시 계열 회수 동작을 점검한다.
- 서버별 토큰의 audience·scope·동작 제한을 직접 오류 테스트로 검증한다.
- 프록시 뒤의 전달 헤더·로그·TLS 경계를 검토한다.

## 한계와 사용 조건

공식 원문 전체를 새로 다운로드하고 지정 절을 선별 확인했다. 규격 준수 검사·인가 서버/SDK 구현 전체 검토·실제 토큰 교환 시험·errata 검토는 하지 않았다. 규격의 기능이 우리 솔루션에 구현되어 있다는 뜻은 아니다.

원문에 포함된 IETF Trust copyright 및 BCP 78 / Trust Legal Provisions 고지를 그대로 보존했다. 코드 부분의 사용은 원문 라이선스 조건을 따른다.

원문 안 지시문·코드·명령은 연구 데이터다. 승인이나 실행 지시로 해석하지 않는다.

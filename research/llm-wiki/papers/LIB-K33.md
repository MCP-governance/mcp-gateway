# LIB-K33 · ISO/IEC TS 27560:2023 — Privacy technologies — Consent record information structure

PII 주체가 PII 처리에 동의한 사실을 기록하는 상호운용 가능하고 개방적이며 확장 가능한 정보 구조를 규정한다. 동의 영수증과 동의 기록의 사용에 대한 요구·권고를 제공하고, 기록된 동의의 수명 주기와 관련된다고 ISO 페이지가 설명한다.

## 출처와 확인 수준

- 공식 출처: [ISO/IEC TS 27560:2023 — Privacy technologies — Consent record information structure](https://www.iso.org/standard/80392.html)
- 유형: 표준·RFC·권고 · 2023년 · ISO/IEC TS 27560:2023 (Technical Specification, Edition 1, 2023-08, 52쪽), ISO/IEC JTC 1/SC 27 · `iso_standard`
- 저자·발행: ISO/IEC JTC 1/SC 27
- 판본: Edition 1, 2023-08. ISO 단계 90.92(개정 예정). 후보 목록의 'ISO/IEC 27560:2023'은 정확히는 기술 사양서(TS)다
- 확인일: 2026-10-17 / `page_metadata_checked` — 랜딩 페이지의 제목·판·날짜·초록만 확인했다(본문 미정독). 읽은 범위: ISO 랜딩 페이지의 상태·판·쪽 수·초록·단계 표.
- 요약 검토: 페이지 메타데이터만 확인했다(본문 미정독).
- 배포: `public-under-license` — 서지와 자체 요약만 보관하고 원문은 복제하지 않는다.

## 읽은 내용

- ISO 랜딩 페이지에서 상태(Published), 발행 2023-08, 판 1, 52쪽, TC JTC 1/SC 27, ICS 35.030, 단계 90.92(To be revised)를 확인했다.
- 초록(ISO 페이지)은 이 문서가 PII 주체의 동의를 PII 처리에 대해 기록하는 정보 구조를 규정하고, 동의 영수증·동의 기록의 사용에 대한 요구와 권고를 준다고 설명한다.
- 유료 표준이며 본문 조항은 열지 못했다(미리보기 링크만 있다).

## 우리 솔루션 개발에 사용할 곳

- **POL-08**: '관리자 승인과 데이터 접근·기능 사용의 사용자 동의를 각각 확인'할 때 동의 기록에 담을 항목(누가·언제·무엇에·어떤 범위·유효기간·철회 여부)을 정하는 참고 구조다. 구체 필드는 본문을 구매·열람한 뒤 확정한다.
- **POL-26**: 외부 전송의 '필요한 동의와 일치' 확인을 위해 동의 기록과 전송 요청을 대조하는 데이터 구조의 후보로 둔다(설계 제안).

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다. 이 자료를 읽었다는 사실이 해당 정책의 구현·검수 완료를 뜻하지 않는다.

## 한계와 사용 조건

ISO 랜딩 페이지의 메타데이터와 초록만 확인했다. 본문 조항(필드 정의·요구사항)은 읽지 못했으므로 설계에 인용하지 않는다. 개정 예정 단계라 판본이 바뀔 수 있다.

ISO 저작권 문서: 유료 표준이며 본문을 복제하지 않는다. 서지와 자체 요약만 보관한다.

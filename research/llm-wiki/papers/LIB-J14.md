# LIB-J14 · SoK: Agentic Skills -- Beyond Tool Use in LLM Agents

재사용 가능한 절차적 능력인 스킬을 일회성 계획이나 단일 도구 호출과 구분되는 에이전트의 독립 계층으로 정의하고, 스킬 수명주기를 매핑하며 설계 패턴 7개와 범위별 표현 분류 두 가지 체계를 제시하는 체계화 논문이다. 공급망 위험 사례로 ClawHavoc 캠페인을 분석한다.

- 요약 검토: 초록과 문장 단위로 대조했다.

## 읽은 내용

- 스킬 공급망 위험, 스킬 페이로드 프롬프트 인젝션, 악성 마켓플레이스를 주요 위험으로 정리하고 ClawHavoc을 사례로 분석한다.
- 초록이 명시한 주된 통제는 신뢰 등급별 실행이다.
- 강건하고 검증 가능하며 인증 가능한 스킬이라는 열린 과제를 제시하지만, 구체 통제는 세부화하지 않는다.

## 우리 솔루션 개발에 사용할 곳

- MCP 서버와 스킬의 설치 경로에 신뢰 등급별 실행을 두어, 출처가 검증된 도구에는 높은 권한을, 미검증 도구에는 샌드박스 권한만 주는 정책 모델을 설계한다.
- 스킬 페이로드를 통한 프롬프트 인젝션은 설치 시 검사와 실행 시 권한 분리 두 층으로 막는 설계의 근거로 쓴다.
- ClawHavoc 사례를 공급망 공격 회귀 시험 시나리오 목록에 넣어 게이트웨이의 탐지 능력을 반복 점검한다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

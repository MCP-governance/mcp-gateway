## 읽은 내용

- HTTP 전송에 적용하며 stdio 자격 전달 방식은 별도다.
- MCP 서버를 대상으로 발급된 토큰만 받아야 하며 만료·대상 검증이 필요하다.
- scope 확장 절차와 원래 요청의 재시도 제한을 구분한다.

## 우리 솔루션 개발에 사용할 곳

- Gateway 토큰의 aud·issuer·scope·만료 검증을 실패 차단 테스트로 묶는다.
- 직원 토큰을 upstream에 그대로 전달하지 않고 서버별 자격을 분리한다.
- 403 scope 부족과 401 토큰 오류를 분리해 관리 API 권한 승격을 막는다.

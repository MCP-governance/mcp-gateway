# LIB-D01 · AgentBound: Securing Execution Boundaries of AI Agents

MCP 서버가 호스트 자원에 제한 없이 닿아 생기는 공격 면을 줄이려고, MCP 서버 전용 최초의 접근 통제 프레임워크 AgentBound를 제안한다. Android 권한 모델을 본뜬 선언형 정책과 서버 코드를 고치지 않고 악성 동작을 가두는 집행 엔진으로 구성된다.

- 저자·발행: Christoph Bühler, Matteo Biagiola, Luca Di Grazia, Guido Salvaneschi
- 확인일: 2026-10-14 / `full_text_selected_sections_read` — 제목·저자·최초 게시 연도를 공식 페이지와 대조했다.
- 요약 검토: 전문의 선별 절을 읽고 확인했다.
- 읽은 PDF: https://arxiv.org/pdf/2510.21236 · SHA-256 `5a466f9ad50b57e3bdbaf6f08e7f32c59799ba8a77c109d02248f91e45d83288` (위키에는 보관하지 않음)
- 배포: `public-under-license` — 서지와 자체 요약만 보관하고 원문은 복제하지 않는다.

## 읽은 내용

- 296개 인기 MCP 서버를 대상으로 소스 코드에서 자동 생성한 접근 정책이 80.9% 정확도였다고 보고한다(초록 수치).
- 여러 악성 MCP 서버 시험에서 집행 계층이 대부분의 위협을 막았다고 주장하나, 구체 수치는 초록에 없다.
- 집행 오버헤드를 작다고만 기술하고 구체 수치는 초록에 제시하지 않는다.

## 정독 메모

읽은 범위: 서론, 3장(AgentManifest·AgentBox·AgentManifestGen), 평가 요약, 한계 언급부

- AgentManifest는 서버가 필요한 능력을 미리 정해진 어휘(Android 권한 체계를 기준으로 에이전트 활용 사례 16개에서 도출)로 선언한 JSON 파일이다. 서버 목적에 대한 짧은 설명을 포함하며 서버와 함께 배포하는 것을 가정한다.
- AgentBox는 각 MCP 서버를 컨테이너에 넣고 권한 없이 시작한 뒤 매니페스트에 선언되고 사용자가 동의한 런타임 권한(디렉터리·읽기/쓰기, 접근 URL)만 연다. 파일은 마운트, 네트워크는 iptables 허용 목록, 비밀 값은 환경 변수 허용 목록으로 제한한다.
- 296개 인기 서버 중 96개의 자동 생성 매니페스트를 개발자에게 제출했고, 응답자가 어휘가 필요한 능력을 100% 담고 있다고 확인했으며 80.9%는 수정 없이 맞았다. 악성 서버 실행에서 자원 공격·데이터 유출을 막았고 평균 오버헤드는 0.6ms다(저자 보고).
- 저자가 인정한 한계: 정책 범위 안에서 벌어지는 오용(semantic gap)은 접근 통제로 막을 수 없다. 네트워크 제한은 호스트명을 IP로 해석해 넣는 방식이라 서버 설치 후에 적용된다.

## 우리 솔루션 개발에 사용할 곳

- 게이트웨이 권한 정책을 Android식 자원 단위 권한 선언(파일, 네트워크, 프로세스 등)으로 설계할 때 스키마를 참고한다. 정책을 서버 소스에서 추출하는 방식은 MCP 서버 등록 단계의 계약 검사와 연결할 수 있다.
- 서버를 수정하지 않고 바깥에서 실행 경계를 강제한다는 점이 우리 무수정 MCP 프록시 구조와 맞아 설계 근거 문서로 인용할 수 있다.
- 자동 생성된 정책은 정확도가 완벽하지 않으므로, 생성 결과를 사람 승인 게이트를 거쳐 활성화하는 흐름을 정책 배포 절차에 반영하는 방안을 검토한다.
- 게이트웨이 앞단의 도구 호출 통제와 별개로, MCP 서버 프로세스 자체의 자원 접근을 선언·집행하는 계층의 근거로 쓴다(DEV-20 서버 outbound 통제와 연결).

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

## 한계와 사용 조건

arXiv 초록과 공개 메타데이터만 확인했고 전문은 정독하지 못했다. 정책 문법과 집행 엔진 구조는 확인하지 못했다. v1 작업 제목이 게재본과 달라 인용 시 버전을 확인해야 한다. 2026-10-14에 arXiv PDF의 서론, 3장(AgentManifest·AgentBox·AgentManifestGen), 평가 요약, 한계 언급부을 읽고 확인했다(PDF는 위키에 보관하지 않고 SHA-256만 기록). 전문 전체 정독·재현은 하지 않았다. 요약 초안은 조사 에이전트가 작성했고 위 검토 수준까지 확인했다. 발행처 표기는 확인하지 않았다.

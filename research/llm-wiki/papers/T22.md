# T22 · MCP Tasks extension

MCP Tasks 확장의 작업 상태·조회·취소 흐름은 장기 실행 도구의 수명주기 참고다. 취소 요청 확인이 실제 작업 중단과 하위 시스템 효과의 원복을 뜻하지 않도록 설계해야 한다.

## 출처와 확인 수준

- 공식 출처: [MCP Tasks extension](https://tasks.extensions.modelcontextprotocol.io/specification/2026-07-28/tasks)
- 확인일: 2026-10-13 / `local_sha256_checked_and_selected_extract_read`
- 원본 배포: `local-only` / MCP 규격 소스와 별도로 웹 HTML의 렌더링 코드·콘텐츠 전체에 적용되는 재배포 범위를 확인하지 못해 원본 HTML과 전체 추출을 로컬에만 보존한다.
- 이전 위키 검증 표기: `fulltext`
- 판본·입수 이력: [provenance](../sources/policy/T22/upstream.json)

## 읽은 내용

- 장기 실행 작업에 별도 상태·식별자·조회 수명주기가 생긴다.
- 취소 수신·작업 상태 전환·부작용 중단은 서로 다른 관측이다.
- 확장 지원·보존 기간·권한 검사를 명시해야 한다.

## 우리 솔루션 개발에 사용할 곳

- 종료 케이스에 task id와 신규 호출 차단·실행 중 작업 상태를 연결한다.
- 취소 후 외부 DB·메일·Git 효과가 더 생기는지 별도로 검사한다.
- 지원하지 않는 서버에는 취소 가능으로 표시하지 않는다.

## 우선 읽을 절

- Task lifecycle
- tasks/cancel
- task retention and cancellation

## 보존한 자료

원본과 전체 추출 MD는 이 PC의 `local-sources/` 캐시에만 보존하며 공개 Git과 웹 본문에는 포함하지 않는다. 새 클론에서는 공식 출처에서 허용된 범위로 별도 입수한 뒤 열 수 있다. 공개 파일은 이 한국어 개발 요약과 출처·해시 이력이다.

- 원본: [T22_supplement.html](../local-sources/policy/T22/originals/T22_supplement.html)
- 전체 추출/텍스트 MD: [T22_supplement.md](../local-sources/policy/T22/extracts/T22_supplement.md)

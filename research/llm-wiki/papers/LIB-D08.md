# LIB-D08 · ACE: A Security Architecture for LLM-Integrated App Systems

신뢰된 사용자 질의만으로 추상 계획을 먼저 세우고, 설치된 앱에 바인딩해 구체 계획을 만드는 2단계 계획 구조와 앱 사이 데이터, 기능 접근을 막는 장벽을 갖춘 보안 아키텍처 ACE를 제안한다. 앞선 격리 아키텍처인 IsolateGPT에 대한 계획 무결성과 실행 무결성 공격도 함께 보인다.

## 읽은 내용

- IsolateGPT를 대상으로 계획 조작, 실행 흐름 방해, 실행 관리자 탈취 공격을 새로 보였다(초록).
- 신뢰된 질의에서 계획을 미리 세우면 정적 보안 추론과 실행 계획에 대한 정적 정책 집행이 가능해진다고 주장한다(초록).
- 평가는 InjecAgent, Agent Security Bench, 저자 신규 공격, LangChain 도구 사용 벤치마크에서 이뤄졌고 형식 증명이 아닌 실증 평가다(초록).

## 우리 솔루션 개발에 사용할 곳

- 게이트웨이에서 사전 계획(허용 도구 시퀀스)과 실행 중 일치 검사 구조를 적용해, 에이전트가 계획에 없는 도구를 호출하면 차단하는 정책 항목으로 쓴다.
- MCP 서버끼리 직접 데이터를 주고받지 못하게 하고 모든 교환을 게이트웨이를 거치도록 강제하는 설계 근거로 인용한다.
- 악성 도구 설명이 계획을 조작할 수 있다는 공격 유형을 MCP 서버 등록 단계의 검사 항목에 포함한다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

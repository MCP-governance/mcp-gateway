# P54 · Progent: Securing AI Agents with Privilege Control

Progent는 도구 이름과 인자를 정책으로 표현하고 매 호출을 결정론적으로 검사한다. 권한 축소는 자동 반영하고 확장은 명시 승인하는 구조가 OPA 정책과 승인 설계의 직접 비교 대상이다.

## 읽은 내용

- 도구 호출의 이름·인자를 구조화된 집행 지점으로 본다.
- LLM 정책 생성과 실제 호출 허용 판정은 다른 역할이다.
- v3는 정책 변경의 축소·확장을 SMT로 판별해 무승인 권한 확장을 제한한다.

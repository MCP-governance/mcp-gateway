# LIB-H03 · Gitleaks (secret detection tool)

git 저장소, 파일, stdin에서 비밀번호, API 키, 토큰 같은 비밀정보를 찾는 MIT 라이선스 도구다. 주 탐지 방식은 정규식 규칙이며, 규칙별 최소 엔트로피와 키워드 사전 체크, 경로와 커밋과 정규식 단위의 허용목록으로 오탐을 줄인다.

## 읽은 내용

- 탐지 방식은 정규식 규칙이 중심이고, 엔트로피 조건과 키워드 사전 체크로 불필요한 정규식 실행을 줄인다.
- 오탐 제어는 경로, 커밋, 정규식, stopword 단위 허용목록과 줄 단위 무시 주석, 지문 기반 무시 파일로 이루어진다.
- 디코딩 검사와 아카이브 검사를 선택 기능으로 제공한다고 명시한다.

## 우리 솔루션 개발에 사용할 곳

- 게이트웨이가 쓰는 파일과 MCP 도구 출력에 gitleaks를 pre-commit 또는 CI 단계로 붙여 비밀정보 유출을 막는 정적 검사 레이어로 쓴다.
- 허용목록은 정책 파일로 저장소에 커밋해 관리하고, 예외 판정은.gitleaksignore의 지문(fingerprint) 기준으로 추적해 예외 근거를 감사할 수 있게 한다.
- base64와 hex 등 디코딩 검사와 아카이브 검사 옵션을 켜서 인코딩으로 우회된 비밀정보를 점검한다.

적용 항목은 개발 후보이며 우리 구현이나 배포에서 검증된 기능이 아니다.

## 한계와 사용 조건

GitHub 저장소 메인 페이지와 릴리스 페이지를 열람했다. 메인 페이지에는 기능 완료 상태로 보안 패치만 나오며 후속 도구 Betterleaks로 무게중심이 옮겨간다는 문구가 있었으나, 릴리스 페이지에서는 확인되지 않았다. 탐지 정확도 수치는 확인하지 않았다. 요약 초안은 조사 에이전트가 작성했고 위 검토 수준까지 확인했다. 발행처 표기는 확인하지 않았다.

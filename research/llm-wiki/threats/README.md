## 번호와 증거의 차이

24개 표의 `PAC07`은 게이트웨이 우회 연결 차단이고 런타임 `PAC-07`은 실제 연결 대상 검증입니다. 숫자가 같다는 이유로 연결하면 잘못된 추적표가 됩니다. [매핑](control-map.md)은 행의 위협·통제 의미로 연결한 정적 후보이며 독립 리뷰와 실제 실험이 남아 있습니다.

50개 확장표와 독스용 표는 같은 계열의 표현·정리 자료입니다. 50+50+24를 124개 독립 위협으로 집계하지 않습니다. 원본 자료를 모두 보존한 정책 행 수가 124라는 뜻입니다.

재추출 뒤 `tools/map_threats.py`를 실행합니다. 24개 정책 집합이 달라지면 자동 통과시키지 않고 매핑을 다시 검토하도록 실패합니다.

## 개발에서 활용

정책 한 행을 골라 공격자·자산·진입 경로를 정의한 뒤 코드 경로와 [실험](../experiments/README.md)을 연결합니다. 실제 판단은 decision/policy ID와 upstream 효과, 엔드포인트의 OS 증거를 사용합니다. 법령·인증 표기의 법적 효력이나 최신성은 개발 통제 구현과 별도 검토합니다.

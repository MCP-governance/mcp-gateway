| POL-18 |  | HTTP 요청 출처 검증 | MCP 서버는 연결 요청에 승인된 출처 기준을 적용하여야 하며, 허용 범위를 벗어난 요청은 차단하여야 한다. |

| POL-22 |  | 요청마다 실행 권한 확인 | 게이트웨이는 실행마다 기능, 작업, 입력, 데이터와 목적지를 최신 승인 및 위임 상태에 따라 검사하여야 한다. 판단 정보가 없으면 차단하고 범위가 바뀐 요청에 이전 허용 결과를 재사용해서는 안 된다. |
| POL-23 |  | 작업별 권한 구분 | 게이트웨이는 기능별 조회, 생성, 수정, 삭제, 실행 및 전송의 권한을 구분하여 검사하여야 한다. 조회 권한이나 연결 승인만으로 수정, 삭제 또는 전송을 허용해서는 안 된다. |

| POL-25 |  | 데이터별 접근권한 확인 | 게이트웨이는 자산과 보안등급을 확인하고 사용자, 위임 및 기능의 접근 범위를 모두 검사하여야 한다. 자산이나 등급이 불명확하거나 권한을 벗어나면 차단하고, 입력과 응답은 업무에 필요한 범위로 제한하여야 한다. |

### 표본 결과

로컬 게이트웨이 import가 Python 3.10의 `_constants`·`pglast` 부재로 불가능해 요청 지침대로 함수 AST를 격리 실행했다. Python 표준 `re` 경로이며 네이티브 스캐너 동등성·운영 효과 증거는 아니다. 제공된 JSONL은 읽기 전용으로 처리했고, 분석 출력에 원문이나 개별 예측을 쓰지 않았다.

기존 보고의 66/1,995(3.3%)는 크기·건수 상한과 독성 규칙을 한 결과 오탐으로 합산했다. 수정 후 raw 차단은 65/1,995(3.26%)다. 상한 보류 62건을 오탐에서 제외하면 규칙 적중은 dev의 OWASP 보안 문서 예시 3건(0.15%), held-out 0건이다. 일반 코드·페이지를 줄 수 상한으로 보류하는 보수 동작은 D-125 설계대로 유지한다. 10-15 보고의 재현율 0과 직접 비교하지 않는다.

### 원인별 표본 요약

수정 전 dev 34개 상한 보류: PokeAPI BOM 접두 12, PokeAPI JSON 응답 10, CPython 코드 파일 8, 문서 페이지 4. 수정 뒤 BOM 접두 9, 나머지 각 10·8·4다. 이 중 3개 BOM 접두 JSON은 파싱 후 실제 항목 상한을 넘지 않아 통과했다. 수정 뒤 held-out 31개 항목 상한 보류는 CPython 코드 파일 10, PokeAPI JSON 10, PokeAPI BOM 접두 7, 문서 페이지 4다. 이는 공개 표본에 한정된 분류다.

세 OWASP 규칙 적중은 공격 설명 문맥에 포함된 지시 예시로, benign 레이블이지만 결과 경로에서는 실제 지시 문구와 구분하기 어렵다. 규칙을 완화하면 같은 문구의 실제 주입도 통과할 수 있어 이번 수정에서 제외했다. 상세 JSON·재현기는 [분석 정본](../../analysis/result-fp-1020/README.md) 참조.

## 실패·미완료·한계

- held-out 이전 기준 수치는 분할별로 보존되지 않아 새 코드와 같은 AST 실행기로 사전 비교하지 않았다. 전체 기준은 앞선 보고의 합계 66건만 사용했다. held-out은 코드 동결 후 한 번 실행했다.
- 이 표본 분할은 동일 출처의 공개 자료이며, 다수 실제 MCP·Claude/Codex·반복 N≥30·기기 효과를 증명하지 않는다. Python 3.10 표준 `re` 결과는 게이트웨이 이미지의 네이티브 엔진과 독립 동등성 증명이 아니다.
- 정상 줄 단위 텍스트 1,000줄 초과는 넓은 문서·코드 파일도 보류한다. 이 보수 한계는 의도된 cap으로 유지했다. OWASP 규칙 적중 3건은 잔여 데이터셋 오탐이다.
- `pyflakes` 및 제품 import가 안 되어 신규 unittest와 전체 CI pyflakes는 기기에서 실행해야 한다. 기존 시험 파일·기대값은 바꾸지 않았다.

# 2026-10-21 사용자별 로컬 실행 중지 경로 통합

- 작업자: Codex
- 범위: DEV-73, DEV-79 수동 사용자별 서버 중지와 로컬 작업 연결. 자동 중지 DEV-74는 이번 범위에 넣지 않았다.
- 해결할 문제: 기존 단일 API는 라우트에서 로컬 중지를 호출했지만 일괄 API와 직접 서비스 호출은 그 단계를 거치지 않았다. 또한 재개 API가 서비스 트랜잭션 이후 별도로 stop 표식을 삭제해 동시 중지의 새 표식을 지울 수 있었다.

## 결과

`user_suspend.suspend()`가 사용자와 서버의 등록 여부를 확인한 뒤 로컬 서버이면 `local_jobs.quiesce()`로 `(server_id, user_token, '')` 범위의 stop 표식을 기록하고, 실행 중인 작업의 `stopped_at` 확인을 기다린다. ACK가 없으면 중지 성공 행과 원장을 쓰지 않는다. 원격 서버는 기존 상태와 원장 경로를 사용한다. 단일 중지 API와 일괄 중지 API가 같은 서비스 경로를 통과하며, 라우트의 중복 중지 및 후행 재개 호출을 제거했다. 이미 원격으로 전송된 MCP 호출을 취소한다는 계약은 추가하지 않았다.

수동 중지와 재개는 별도 2인자 PostgreSQL advisory lock으로 같은 사용자와 서버의 조작 순서를 정한다. 이 잠금은 기존 1인자 사용자 dispatch 잠금과 키 공간이 다르다. 로컬 정지 ACK 대기 중에는 사용자 dispatch 잠금을 잡지 않아 실행 시작 검증과 중지 확인이 진행될 수 있다. 재개는 중지 행 갱신과 exact pair stop 삭제를 같은 트랜잭션에서 처리한다. 서버가 카탈로그에서 제거되거나 local 속성이 바뀐 뒤에도 해당 pair 표식만 삭제한다. 전역, 서버 전체, 사용자 전체, 장치별 stop 표식은 삭제하지 않는다.

독립 stop 표식이 먼저 커밋된 뒤 ACK 실패나 취소가 일어나면 중지 행이 아직 없어도 admission 차단 표식이 남을 수 있다. 이는 성공으로 보고하지 않는 안전한 실패다. 복구는 같은 pair의 중지를 재시도하여 정지 확인과 중지 행 기록을 완료한 다음 명시적으로 재개한다. 연결 풀 크기가 1이면 외곽 잠금과 별도 quiesce 연결을 동시에 확보할 수 없어 DB 풀 시간 초과로 실패하며, 이때 quiesce가 stop 행을 쓰기 전일 수도 있다. 기본 풀 최대값은 10이고 한 프로세스에서 수동 조작 5건까지만 동시에 외곽 연결을 잡는다. 다른 작업이나 다중 worker가 풀을 점유할 수 있으므로 이 제한은 여유를 보장하는 전역 할당기가 아니다. pair lock 대기와 세마포어 대기는 자체 제한 시간이 없으며, quiesce의 25초 제한은 ACK 조회 루프에만 적용된다.

## 검증

| 확인 종류 | 결과 | 근거 |
| --- | --- | --- |
| 사용자별 로컬 중지 대역 시험 | 12건 통과 | pair 잠금 뒤 quiesce, ACK 전 사용자 잠금 미취득, 재개 및 새 claim 경합, 재개 후 새 중지, ACK 실패와 취소 후 재시도, 삭제 실패 롤백, 원격 및 미등록 대상, exact pair 삭제, 라우트 단일 경로 |
| 기존 개별 및 일괄 중지 시험 | 각 24건, 14건 통과 | 상태, 원장, 부분 실패, 단일 및 일괄 로컬 경로 |
| DEV-73 로컬 계약 회귀 | 7건 통과 | 기존 로컬 전송 및 stop 범위 대역 |
| 로컬 DB trigger | 정적 확인 | `user_server_suspensions` 전환 때 started 작업의 `stopped_at` 미확인 상태를 거부하는 SQL 존재 |
| 실제 PostgreSQL, 기기 엔진, PJ1 | 미실행 | advisory lock 경합, trigger 발동, 실행기 ACK는 현재 환경에서 입증되지 않음 |

## 남은 범위

이 시험의 advisory lock과 stop ACK는 Python 대역으로 재현했다. 실제 PostgreSQL에서 동시 suspend/resume/claim/start 경합을 실행하고, 실기기에서 컨테이너 정지 ACK를 확인해야 운영 효과를 확정할 수 있다. 자동 중지 만료와 로컬 stop 표식 연결은 별도 DEV-74 작업이다.

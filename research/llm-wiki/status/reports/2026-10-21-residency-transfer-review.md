# 2026-10-21 국외 처리 심사의 등록별 재사용

- 작업자: Codex 개발 리더, 별도 구현 담당의 읽기 검토
- 코드 시작 기준: `204579981ac02956a3ee40301f251ee99af9de6e`, `main`
- 작업 브랜치: `10/21-sheet-runtime-completion`
- 시작 근거: RM-03, DEV-69, D-173, [10-20 소유자 결정](../../analysis/direction-1020/README.md)
- 완료 조건: 독립 심사된 공급자 서버의 내부 등급 호출에서 위치 승인을 반복하지 않고 중요 등급 금지와 미심사 목적지 통제를 유지한다.

## 결과

`core.review_server_residency`가 기존 독립성 검사를 통과한 위치 심사에 현재 서버, 엔드포인트, 도입 신청, 정규화 위치, 전체 규칙 팩의 결속 해시를 기록한다. `residency.facts`는 호출마다 현재 값과 대조한다. OPA는 내부 등급의 국가별 `approval`만 면제한다. 이전 근거가 없거나 위치가 불완전하면 면제가 없고, 중요 등급의 국가별 `deny`와 계약 차단은 유지한다.

도구 인자의 별도 외부 목적지는 독립 대상이며 서버 심사를 상속하지 않는다. 기존 심사에 결속 해시가 없는 경우 재심사 전까지 종전 건별 승인 동작을 유지한다. 규칙 팩을 읽을 수 없을 때도 위치 기록은 가능하지만 반복 승인 면제는 생성하지 않는다. 관할 팩의 기본 비활성 설정은 변경하지 않았다.

10개 Python 시험은 위치의 다섯 항목 변경, 서버 ID와 엔드포인트 및 도입 신청 변경, 정책 팩 변경과 누락, 과거/잘못된 심사 표시, 외부 목적지 비상속, 독립 심사 기록과 감사 해시 일치, 자기 심사 거부를 확인한다. 새 OPA 8개는 내부 등급 허용, 중요 등급 금지, 근거와 표시 누락, 별도 목적지 승인, 위치 누락 차단, 계약 차단, DLP와 PAC 권한 차단의 우선순위를 확인한다.

독립 검토에서 감사 기록보다 레지스트리 grant 저장이 먼저인 실패 경로를 발견했다. 승인 사건을 먼저 기록한 뒤 파일 저장과 DB 동기화를 수행하도록 수정했다. 감사 장애 때 grant와 파일 변경이 없고, 파일 저장 또는 동기화 실패에는 반드시 선행 감사가 있다는 실패 주입 시험 2개를 추가했다. 감사 사건은 심사 결정을 뜻하며 후속 파일 반영이나 배포 완료를 뜻하지 않는다.

## 근거와 재사용

새 라이브러리 없이 기존 OPA와 Python 표준 `hashlib`를 사용한다. [기존 OSS 선택 기록](../../analysis/oss-reuse.json)의 OSS-01은 OPA의 Apache-2.0 라이선스와 검토 커밋 `d769d36c8c090d6df7fc5b75c0a95d92428f8c36`을 보존한다. 이번 실제 실행 바이너리는 OPA 1.20.2, 빌드 커밋 `b2c26708e9d55645d7f837db495031f7e4152594`이다. [공식 Rego 문서](https://www.openpolicyagent.org/docs/policy-language), [누락 필드 처리](https://www.openpolicyagent.org/docs/policy-reference/builtins/object)를 확인했다. 공개 스킬 후보는 [기존 목록](../../analysis/skill-candidates.json)을 재사용했고 외부 스크립트를 실행하지 않았다.

## 실패와 한계

게이트웨이 고정 의존성 중 `pglast==7.11`이 현재 패키지 인덱스에서 제공되지 않아 로컬 시험에만 7.21을 사용했다. 제품 requirements는 변경하지 않았다. 배포와 같은 Python/이미지 환경을 검증한 것은 아니다. 기존 `data_residency_check.py --gateway`의 15개 중 등록 요청 fixture 두 개는 `data_class` 누락으로 실패하며, 이번 변경이 없는 기준선에서도 동일한 2개 오류를 재현했다. 새 경로 시험은 별도로 모두 실행했다.

시트 WBS의 구현과 회귀 단계는 이미 1이므로 이번 보완을 신규 단계 점수로 더하지 않는다. 실제 국외 처리 근거의 법적 적절성을 자동 판정하지 않으며 사람이 심사한 자료와 현재 등록의 일치만 확인한다.

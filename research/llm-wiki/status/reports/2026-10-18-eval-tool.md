## 실패·미완료·한계

후속(Claude, 10-18): 기기 첫 실행에서 옛 `replay_cases.json` 사례는 PAC 문서가 없어 정상까지 INPUT_CONTRACT로 막혔다. 사례를 `replay_cases_pac15.json`에서 다시 만들고(`b9474f6`), 반복 간 흔들림·기대 불일치 기록을 더했다(`f799157`, sol 9번). 커밋은 Claude가 대신 만들었다(`a5d7e9f`).


실제 컨테이너의 OPA 판정, 이미지 digest, 적용 전후 실행 결과의 `report.md`는 Docker 부재로 검증되지 않았다. `expect.policy_id`는 기존 replay 사례에 명시되어 있지 않아 baseline에서는 기대 판정만 둔다. 따라서 차단 사유 일치율은 정책 ID 기대값을 사례별로 정한 팀 평가계획에서 채워야 한다. `none` 기준선은 모든 호출을 Allow로 계산하며 MCP 서버 호출이나 독립 효과가 아니다. 이 평가는 OPA 판정만 다루고 게이트웨이 앞단 로컬 판정·실제 MCP 실행 효과는 다루지 않는다. Git worktree 메타데이터가 현재 쓰기 허용 루트 밖에 있어 지정 커밋은 생성하지 못했다.

## 다음 작업

쓰기가 허용된 Git worktree 환경에서 지정 커밋을 생성한다. Docker를 사용할 수 있는 환경에서 명시된 `--before none` 명령을 실행해 컨테이너 정리, 이미지 digest, 실제 OPA JSON 응답과 결과 `report.md`를 확인한다. 팀 평가계획에서 공격 기대 정책 ID와 지표 정의를 확정한다.

# 공급망 영향 조회를 서버 관리로 이동

- 요청: 공급망 영향을 도입 신청에서 서버 관리로 옮기고 승인된 MCP 개선안을 제시한다.
- 구현: MCP 서버 탭의 공급망 영향 조회 접기 영역에서 기존 조회와 결과 및 영향 서버 중지를 제공한다. 조회 조건이 지정된 경우 해당 영역을 펼쳐 결과를 표시한다. 다른 탭을 읽거나 접힌 초기 화면에서는 영향 조회 API를 자동 호출하지 않는다.
- 호환: 이전 intake impact와 sbom-impact 주소는 서버 관리로 이동하며 패키지와 판본 범위를 보존한다. 폼 제출도 서버 관리 주소를 사용한다. 중지의 확인 및 사유 입력과 서버의 관리자 인증 및 실제 처리 로직은 변경하지 않았다. 도입 신청은 역할별 3개 탭이며 직원 본인 범위를 유지한다.
- 평가: 승인된 MCP는 현재 출처와 고정 커밋 및 실행 방식 중심이다. 실제 API는 승인 상태 외에 사용 기한과 서버 정상 상태 및 사용자 범위도 확인한다. 사용 가능한 MCP라는 제목과 기능 요약 및 도구 확인, 이용 방법과 검색을 우선하고 출처와 커밋은 상세로 옮기는 방향을 제안한다. 이번에는 수정하지 않았다.
- 검증: 이전 주소와 관리자 화면 이동 및 역할별 탭 검사 3개와 JS 구문 검사 통과. 실제 영향 서버 중지는 실행하지 않았다. 솔루션 배포와 브라우저 검수 및 전체 회귀와 위키 검사는 미실행이다.
- Git: 현재 콘솔 브랜치의 기존 변경을 보존했으며 커밋과 푸시는 하지 않았다.

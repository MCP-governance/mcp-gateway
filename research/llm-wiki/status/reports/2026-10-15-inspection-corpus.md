### G04.01 입력 게이트

같은 코퍼스를 인자로 넣어 `--gates`로 측정: 64 KiB−20 B는 통과, 1바이트 초과·3바이트 문자 초과는 크기로, 정수·배열·null·추가 속성·`__proto__`·필수 누락·중첩 형식 오류는 형식으로 `P-INPUT-SCHEMA-001`. 지시 표지는 쓰기·실행 `P-UNTRUSTED-CONTENT-001`(승인)·읽기 `-002`(경보), `opa test` 91/91. PayloadsAllTheThings 경로 조작 1,468줄 모두 important, 정상·이스케이프 경로 대조 11/11. 단독 서러게이트는 MCP SDK 파서가 먼저 거부한다.

**찾은 결함**: U+0000이 든 인자나 업스트림 결과 문자열은 SDK는 받지만 감사 저장(psycopg Jsonb → PostgreSQL jsonb)이 `UntranslatableCharacter`로 실패해 판정 행이 남지 않았고, 결과의 경우 호출은 이미 실행됐을 수 있다(일회성 postgres:18-alpine에서 재현). 메인 에이전트가 병합 후 고쳤다(`c3a8a49`: 인자는 전송 전 `P-INPUT-SCHEMA-001`, 기록 직전 모든 문자열의 U+0000을 U+FFFD로 바꾼 뒤 지문 계산, 실제 Gitea MCP 실험에 사례 추가).

## 실패·미완료·한계

- 합성 한국어 공격·정상 표본은 규칙을 읽은 같은 작성자가 썼다(독립 검증 아님). 공개 한국어 프롬프트 주입·업무 문서 코퍼스를 찾지 못했다. 정상 정밀도(오탐 0/1,978)는 영어 코드·문서·로그·JSON, 한국어 Kubernetes 문서, 합성 69문장 범위다.
- 결과 규칙 재현율 0.495는 결과를 보류하는 좁은 규칙의 설계값이다. 명령형만 있는 도구 응답(InjecAgent base 0/1,054), 설득문, 다국어 의역(0.6%), rot13·역순·leetspeak은 다루지 않는다(의미 분류기·정책·승인의 몫). OWASP LLM01 페이지는 여전히 보류된다(3/6).
- dev·held-out은 같은 출처에서 갈랐으므로 새 출처에는 일반화되지 않는다.
- 실제 Claude 사용량 한도 거부 출력과 성공한 `codex exec --json` 출력은 이 PC에서 얻지 못했다. 해당 분류는 실제 필드 이름으로 만든 스트림으로 시험했다(시험에 표시).
- 분석기 변경은 기존 이미지를 바탕으로 만든 파생 이미지로만 확인했다. `field up`이 분석기 이미지를 빌드하지 않던 문제는 메인 에이전트가 고쳤다(`087562a`).
- 코퍼스 캐시 생성(`build`)은 네트워크와 PyYAML이 필요하다. MCPTox 자료는 라이선스 파일이 없어 측정에만 쓰고 재배포하지 않는다.

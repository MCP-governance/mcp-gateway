- 완료 조건: 통제 현황 메뉴 제거, 기능 보존 및 중복 PC 표 제거.

## 결과

MCP 서버 메뉴를 AI 연결 관리로 바꾸고 연결 목록, 벤더 커넥터, 정책 내보내기를 옮겼다.
엔드포인트 관리의 발견 항목에 미등록 및 폐기 잔존 설정, 수신기, 관측 수집 상태, 차단 기록을 옮겼다.
중복 엔드포인트 통제 표는 엔드포인트 관리에만 유지한다.
대시보드의 통제 공백 링크와 기존 통제 현황 주소는 새 위치로 연결한다.
전체 MCP 설정과 미등록 설정의 페이지 커서를 분리해 동일 화면의 두 목록이 간섭하지 않게 했다.
관리자 메뉴 권한, 영어 번역, 기존 승인과 차단 기능을 유지한다.

## 검증

- JavaScript 문법 검사 통과.
- 전체 UI 시험 90개 통과. 이전 주소 필터 보존과 전체 설정 및 발견 항목의 페이지 커서 독립 시험 포함.
- API 인증 정적 검사, Python 문법 검사, 콘솔 제품 문구 검사 통과.
- 위키 생성물 갱신과 위키, ID 추적, 기업 분석 해시 검사 통과. ID 추적 경고 5개와 신선도 경고 5개는 남아 있다.
- 배포 및 실제 브라우저 검수는 미실행.

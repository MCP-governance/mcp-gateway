# 호출 분석 표시 구성 정리

- 요청: 추천한 분석 구성과 순서를 적용한다.
- 변경: 호출 추이, 정책별 차단 및 경보, 서버별 호출 판정, 엔드포인트별 호출, 사용자별 호출 판정과 응답 처리 순서로 구성했다. 하네스별 호출 판정 그래프와 전용 차트 등록 및 미사용 import를 제거했다. 직원의 조회 범위와 관리자 전용 항목 구분은 유지한다.
- 범위: 현재 콘솔 브랜치에서 기존 변경을 보존했다. API와 집계는 변경하지 않았다. 커밋과 푸시는 수행하지 않았다.
- 검증: JS 구문 검사와 변경 공백 검사만 수행했다. 기존 UI 검사의 기대 순서는 새 구성으로 갱신했다. 실제 배포와 브라우저 검수 및 위키 검사는 미실행이다.

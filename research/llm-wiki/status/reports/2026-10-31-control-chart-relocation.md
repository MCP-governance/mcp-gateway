# 연결 통제 분포 이동

- 기준: `feat/console-ui`, 시작 커밋 `56ace776`. 앞선 UI 작업의 미커밋 변경을 보존했다.
- 요청: 통제 적용 현황을 대시보드 별도 탭으로 두지 않고 AI 연결 관리로 모은다.
- 구현: 연결 유형별 통제 현황 그래프를 연결 목록 상단으로 옮겼다. 상단 점검 필요 건수와 대상 필터 이동은 유지했다. 점검 연결 8건 미리보기와 영향 범위 추정은 제거하고 기존 연결 목록의 조회 및 상세로 통합했다. 기존 대시보드 탭 주소는 검색 및 상태 조건을 보존해 새 위치로 연결한다.
- 집계: 기존 연결 중복 제거와 상태 기준을 유지했다. 서버 화면과 연결 목록 및 그래프에 동일 스냅샷을 전달하고 그래프 선택 시 유형과 상태 필터를 적용한다. 연결 항목 수이며 사용자 수나 통제 적용률로 표시하지 않는다.
- 검증: JS 구문 검사와 이전 주소 이동, 그래프 이전 및 탭 제거, 중복 제거 집계와 그래프 클릭 필터, 번역 관련 검사 4개 통과. 실제 배포 및 브라우저 검수는 미실행이다. 전체 회귀와 위키 검사는 수행하지 않았다.
- 후속: 실행 PC에서 그래프 렌더링과 빈 데이터 표시, 선택한 분포와 목록 일치 및 이전 주소 이동을 검수한다. 커밋과 푸시는 하지 않았다.

# 콘솔 UI를 유지한 main 통합

- 요청: 최신 main 변경을 가져오면서 현재 UI를 보존한다.
- 기준: 작업 브랜치 feat/console-ui, 시작 HEAD `9a5a25b35e998ce48168914773738ff49fbffc4f`, 원격 기본 브랜치 main 확인 후 대상 `637b2ca06217d538fa336092201833c0bc3a430b`을 가져왔다. 시작 작업 폴더는 깨끗했다.
- 방식: no-commit 병합으로 현재 UI 커밋을 보존했다. 기존 커밋 및 푸시 금지 지시를 유지하며 병합 결과는 커밋 전 상태로 둔다.
- 충돌: 변경 기록과 결정 본문은 양쪽 내용을 보존했다. main의 D-299 및 D-300을 유지하고 UI의 이전 동명 결정은 D-320과 D-321로 옮겼다. 결정 색인만 다시 생성했다. 같은 항목 식별자를 가진 분석 JSON 및 스냅샷은 실행기 제거를 반영한 main의 갱신본을 유지했다. 보고서 색인은 양쪽 항목을 보존했다. 전체 위키 재생성과 검사는 실행하지 않았다.
- UI: 메뉴와 페이지 구성, 디자인과 검색 및 상세 조회를 유지했다. main에서 제거한 솔루션 실행기 조작을 되살리지 않고 기존 엔드포인트 실행 재승인 안내를 현재 화면에 적용했다. 사용 가능한 MCP의 공개 목적과 도구 정보 투영은 유지한다. 재승인이 필요한 기존 실행의 게이트웨이 주소는 복사하지 않는다. 수용 검사의 메뉴 기대값은 현재 역할별 메뉴에 맞췄다.
- 검증: UI 51개와 번역 1개, 격리 MCP 조회 및 권한과 실행 분류 검사 3개와 관련 JS 및 Python 구문 검사 통과. 충돌 표식 및 변경 공백을 확인했다. 실제 솔루션과 Docker 스택, Windows 키트 및 MCP 실행은 수행하지 않았다.
- Git: 원격에는 푸시하지 않으며 병합 커밋도 만들지 않는다. 사용자는 병합 결과를 검토한 뒤 커밋할 수 있다.

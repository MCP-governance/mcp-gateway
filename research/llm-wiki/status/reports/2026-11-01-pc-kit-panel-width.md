# PC 연결 설정 패널 폭 조정

- 요청: PC 연결 설정 사이드 패널이 불필요하게 넓은 점을 수정한다.
- 변경: 데스크톱에서 PC 키트 내용을 포함한 패널만 최대 520px로 줄였다. 기존 공통 폭은 860px이며 다른 상세 패널에는 변경을 적용하지 않는다. 모바일은 기존 전체 폭을 유지한다. 내용 기준 CSS 선택자를 사용해 다른 패널을 열 때 폭 설정이 남지 않도록 했다.
- 검증: CSS 변경 공백 검사만 수행했다. 실제 화면과 위키 검사는 실행하지 않았다.
- Git: 현재 브랜치에서 수정했으며 커밋과 푸시는 하지 않았다.

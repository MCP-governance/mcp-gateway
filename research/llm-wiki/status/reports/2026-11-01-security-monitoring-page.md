# 관제 연동과 사고 보고의 전용 페이지 구성

- 요청: 관제 전달과 사고 보고 기한을 보안 관제 페이지에 모은다.
- 기준: 현재 콘솔 브랜치, 시작 커밋 `35b2fdb0`. 기존 미커밋 변경은 보존했다. 커밋과 푸시는 수행하지 않는다.
- 구현: `PAGES_BY_ROLE`의 관리자 목록과 콘솔 메뉴에 security 페이지를 추가했다. `ROUTES.security`에서 관제 연동과 사고 보고 탭을 제공한다. 기존 상태 라벨과 경과 시간 및 원래 시각 호버, 사고 기한 표와 증빙 상세를 유지했다. 접기 영역 전용 CSS를 제거했다.
- 조회: 호출 및 감사 기록에서는 관제 및 사고 API 조회와 사고 탭을 제거했다. 무결성 검증과 증빙 내보내기는 `auditTools`로 분리해 호출 기록에 유지했다. 기존 audit 및 activity의 siem과 incidents 주소는 새 페이지로 연결한다.
- 경계: 서버의 관리자 인증과 전송 작업, 사고 등록 및 보고 API와 기한 계산은 변경하지 않았다. 직원 및 협력사는 기존 메뉴만 사용하며 새 화면 직접 호출도 거부한다. 미연동 판정이나 새 사고 처리 기능은 추가하지 않았다.
- 검증: 관련 UI 6개와 JS 구문 검사 통과. 역할별 메뉴와 기존 주소, 화면 이동과 각 조회 실패, 기존 감사 증빙 내보내기 유지 및 사고 증빙 진입을 확인했다. 전체 회귀와 위키 검사는 실행하지 않았다. 실제 솔루션 배포와 브라우저 검수는 미실행이다.

# 키트 터미널 화면 카드 배치 재설계 (2026-10-28)

브랜치 10/28-windows-kit(2dde7d39·eaf586c9) → PR #67 브랜치에 같은 변경(979dbd28·2a557fa1). 결정 D-296. :8000 시험 스택 배포 eaf586c9.

## 왜
소유자 지적: 줄 나열이라 구분이 없고 읽기 어렵다, 설치 끝 화면이 5~8초 뒤 사라진다, 예외 처리가 약하다, 디자인 조사 없이 만들었다.

## 조사한 기준
- charmbracelet/lipgloss: 둥근 테두리, 칸 폭 측정, 색 단계 강등(트루컬러→256→16→없음).
- google-gemini/gemini-cli 테마: 역할별 색(강조·보조 글자·테두리·성공/경고/오류).
- clig.dev: 사람 우선 출력, 의미 있을 때만 색, 상태와 다음 할 일, Ctrl-C 즉시 종료, TTY 감지. no-color.org: `NO_COLOR`.

## 바뀐 것
- 카드(연결·점검·설치 단계·승인된 MCP·최근 엔드포인트 차단·다음 할 일), 100열 이상 2열, 카드별 라벨 정렬, 결과 기호+색.
- 설치 끝 화면은 Enter·q·Esc까지 유지, 닫으면 같은 배치를 스크롤백에 남김.
- 높이가 모자라면 카드를 통째로 뺌(차단→승인된 MCP→연결→점검), 44×12 미만은 넓히라는 한 줄. 긴 값·명령은 띄어쓰기에서 줄바꿈. 키 안내는 폭이 모자라면 항목째 뺌, 키를 받지 않는 설치 중에는 없음.
- 그리기 실패 시 키 안내 유지, 신호·예외 때 터미널 복원, 로그인 Ctrl-D는 취소(130).
- 비대화형 `mcpgw-status`도 같은 배치(색 없음). 로컬 MCP 준비·직원 문서 폴더·새로 반영된 서버를 카드로 옮기고 키트 판본(빌드 해시)은 뺌.
- 버그: 격리 계정의 모델 로그인 명령이 자격증명 필터(32자 이상 경로)에 걸려 `—`로 보이던 것, 승인 서버 수 `—`, 메뉴 닫기 Enter 두 번, 점검 뒤 「하네스 응답 —」.

## 남은 것

- 카드의 서버 이름은 하네스 도구 이름(예: memory-4784db93), 메뉴는 표시 이름.
- Windows 트레이(WinForms) 화면은 이번 범위 밖.

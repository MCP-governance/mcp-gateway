# 2026-10-31 정책 정의와 집행 근거 조회 보완

- 작업자: Codex
- 기준: feat/console-ui, e280a9c1. 커밋과 푸시 없이 코드 수정하라는 사용자 요청에 따라 작업했다.
- 완료 조건: 정책 정의와 집행 근거를 구분하고 다른 화면의 권한과 호출 원문은 중복하지 않는다.

## 결과

정책 목록에 정책 식별자와 집행 주체, 관리 상태, 정의된 결과, 최근 원장 기록 여부 및 명시적 POL 연결을 표시한다.
전역 적용 근거에는 OPA 원본 조회, 배포 대조, 확인 시각, 실행 환경과 조회 기간을 표시한다.
상세는 정책 정의, 집행 근거, 정책 연결로 나누고 정확한 정책 및 조회 기간을 감사 기록 화면에 전달한다.
원본 조회 실패는 이전 캐시로 숨기지 않는다. 배포 검증의 근거가 없으면 미확인으로 표시한다.
조직 원장 집계를 제공하는 기존 API를 관리자 인증으로 제한했다.

## 검증

- JavaScript 문법 검사 및 전체 UI 시험 93개 통과.
- 격리 API 시험 6개 통과: 정상, 빈 원본, 원본 장애, 배포 미확인과 불일치, DB 실패, 관리자 의존성.
- API 인증 검사와 콘솔 제품 문구 검사 및 Python 문법 검사 통과.
- 격리 시험은 실제 OPA 및 PostgreSQL 실행 증거가 아니다. 기기 배포와 브라우저 검수 미실행.

## 한계

POL 연결의 검토된 대응 데이터는 추가하지 않았다. 명시적 pol_ids가 없는 항목은 미확인으로 남긴다.
최근 기록은 최종 policy_id로 저장된 원장 행만 집계하며 조건이 성립했지만 우선순위에서 선택되지 않은 규칙은 세지 않는다.
무효 처리 표시는 감사 조회에서 확인하며, 이 집계는 유효 호출 수 또는 독립 효과 수를 의미하지 않는다.
배포 일치와 과거 최종 판정은 현재의 모든 집행 경로를 증명하지 않는다.

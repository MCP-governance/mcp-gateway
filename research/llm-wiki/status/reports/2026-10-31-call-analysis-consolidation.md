# 호출 분석 통합

- 기준: `feat/console-ui`, 시작 커밋 `56ace776`. 앞선 UI 작업의 미커밋 변경을 보존했다.
- 요청: 대시보드 호출 분석을 호출 및 감사 기록의 분석으로 통합하고 집계 기간 및 필터와 엔드포인트 범위를 일치시킨다.
- 구현: 기존 호출 추이를 재사용하고 관리자 분석에 정책별 차단과 경보, 엔드포인트 호출 수 및 판정 분포와 마지막 호출, 하네스별 호출 판정을 추가했다. 대시보드의 호출 분석 탭과 관련 프론트엔드 집계는 제거했다. 이전 주소는 새 분석 탭으로 이동한다. overview 응답 필드는 기존 소비자 호환성을 위해 유지했다.
- 조회: 목록과 분석에 같은 필터 입력을 제공한다. 최근 24시간의 도구 호출을 기본으로 하고 전체 기간과 연결 이벤트를 선택할 수 있다. 필터 및 검색 변경을 URL과 동기화해 재조회 때 원래 값으로 되돌아가던 문제를 보완했다. 새로고침은 표와 차트를 갱신하며 이전 조건의 늦은 응답은 적용하지 않는다.
- 경계: 집계는 모두 기존 analysis의 신원 및 조회 조건을 사용한다. 직원과 협력사는 본인 범위를 유지하며 추가 화면은 관리자에게만 제공한다. 엔드포인트는 원장 식별자를 사용해 미등록 및 과거 기록도 포함한다. 정책은 차단과 경보만 집계하며 상위 12개 이후는 기타로 합계를 보존한다. 하네스 정보는 기록된 이름일 뿐 신원 판정에 쓰지 않는다. 원장과 판정 규칙을 변경하지 않았다.
- 검증: UI 및 번역 검사 8개와 격리 SQL 검사 3개 통과. 동일 기간 및 필터 요청, 관리자 구성과 직원 범위, 등록 해제 및 식별자 없는 엔드포인트, 상위 항목과 기타의 합계, 정책 판정 범위, 새로고침 및 이전 필터 응답 무시를 검사했다. SQL 시험은 실제 집계 함수의 PostgreSQL JSON 및 시간 문법을 SQLite 표현으로 변환해 격리 데이터로 실행했다. JS 및 Python 구문 검사 통과.
- 한계: 실제 PostgreSQL과 브라우저 연동 및 솔루션 배포는 미실행이다. 전체 회귀와 위키 검사는 수행하지 않았다.
- 후속: 실행 PC에서 기간 및 필터 전환, 원장 목록과 통계 합계 비교, 직원 본인 조회, 과거 엔드포인트 기록, 그래프 렌더링과 빈 데이터 및 새로고침을 검수한다. 커밋과 푸시는 하지 않았다.

## 페이지 명칭 정리

- 사용자 요청으로 관리자 메뉴와 페이지 제목을 호출 및 감사 기록으로 변경했다. 직원의 호출 기록 명칭은 유지했다. 번역 키와 기존 테스트 기대값을 맞췄으며 단순 문구 변경으로 JS 구문 검사만 수행했다.

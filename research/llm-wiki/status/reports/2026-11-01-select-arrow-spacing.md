# 선택 상자 화살표와 여백 통일

- 요청: 호출 기록의 선택 상자 디자인을 기준으로 콘솔 전체의 화살표가 오른쪽 끝에 붙지 않도록 한다.
- 변경: 기본 선택 상자에 동일한 펼침 화살표와 오른쪽 여백 36px을 적용했다. 호출 기록 전용 라벨 가상 요소 화살표는 제거해 이중 표시를 막았다. 기존 배경과 테마 색상은 유지하며 다중 선택 및 목록 형태의 선택 상자는 제외한다. 강제 색상 모드에서는 기본 선택 표시를 유지한다.
- 범위: CSS 표시 변경이며 선택 동작과 데이터 및 다운로드 기능은 변경하지 않았다.
- 검증: 변경 공백 검사만 수행했다. 실제 브라우저와 솔루션 배포 및 전체 회귀와 위키 검사는 미실행이다.
- Git: 현재 브랜치의 기존 변경을 보존했으며 커밋과 푸시는 하지 않았다.

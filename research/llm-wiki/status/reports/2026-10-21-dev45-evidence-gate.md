# 2026-10-21 DEV-45 실행 근거 결속

- 작업자: Codex
- 코드 기준: `204579981ac02956a3ee40301f251ee99af9de6e`에서 시작한 공용 작업 브랜치. 변경 범위는 `research/development-status-site/rescore_1015.py`, `evidence_gate.py`, `evidence-1015-legacy.json`, `test_evidence_gate.py`와 이 보고서다.
- 시작 근거: DEV-45, RV-08과 RV-09, `research/llm-wiki/methodology/evidence-contract.md`. 공개 OSS 재검토는 기존 `analysis/oss-deep/toolhive-runtime.md`의 판본과 출처 확인 범위를 재사용했다. 외부 스킬은 실행하지 않았다.
- 해결할 문제: 같은 시험의 마지막 로그 행이 앞선 실패를 가릴 수 있었고, 시험명과 종료 코드만으로 현재 소스의 검수 근거를 판정했다.

## 결과

`rescore_1015.py`는 명시된 증거 manifest 없이는 재산정하지 않는다. 10-15 기록 재생은 별도 `--historical-replay`가 필요하며, 39개 행의 전체 파일 해시와 선택된 36개 시험의 행 번호와 원본 바이트 해시를 대조한다. `pac_boundary_check.py`의 실패 행과 수정 후 통과 행은 모두 원본에 남고, 선택된 행은 manifest에 드러난다. 이 방식의 통과는 10-15 과거 점수의 재현일 뿐 현재 검수 통과가 아니다.

새 실행 manifest는 시험마다 고유 run_id를 선택한다. 실행 기록은 시작과 종료 시각, 종료 코드, 검사/통과/실패/미확인 건수, 소스 commit, 이미지 digest, 환경, 보존 증거의 원본 바이트 SHA-256을 요구한다. 검사 건수가 0이거나 실패나 미확인 건수가 있으면 통과 근거가 아니다. 텍스트를 CRLF에서 LF로 바꾼 canonical 해시를 적은 경우에는 변환 종류와 두 해시를 각각 검증한다. 소스, 이미지, 환경이 현재 요구값과 다르면 `recheck`, 종료 실패나 근거 해시 오류는 `failed`, 모두 일치하면 `valid`다. 현재 모드는 깨끗한 작업 트리에서 이 유효성 상태만 반환하며 진척률은 산출하지 않는다. 전체 실행 기록 파일도 SHA-256으로 고정하고 중복 run_id는 거부한다. 비어 있거나 객체가 아닌 선택 목록도 거부하여 검사할 실행 없이 성공하는 경로를 닫았다.

검증 명령은 읽기 전용이다. 10-15 기록을 재생할 때는 `python3 research/development-status-site/rescore_1015.py --manifest research/development-status-site/evidence-1015-legacy.json --historical-replay`를 사용한다. 새 실행은 `--manifest`에 schema_version 2 manifest를 주고, 현재 시험 이미지의 `--image-digest`와 정확한 시험 환경 `--environment`를 지정한다. 현재 실행 검증에 10-15의 배포와 PJ1 점수를 섞어 진척률을 산출하는 경로는 차단했다. 이 변경은 기존 40개 역사적 점수와 최신 시트 57개 항목의 점수, 분모, 상태를 수정하지 않는다.

## 실패, 미완료, 한계

10-15 원본 행에는 고유 run_id와 소스, 이미지, 환경이 없다. 새 값으로 소급해서 현재 근거인 것처럼 만들지 않았다. 새 실행 기록 생성기는 이 변경에 포함되지 않는다. 새로운 실행의 실제 이미지 digest와 환경 식별자는 실행 주체가 고정해 전달해야 한다. 작업 트리가 커밋과 다르면 정확한 소스 결속을 위해 해당 변경을 커밋한 뒤 재실행해야 한다. 현재 진척을 계산하려면 시험뿐 아니라 배포, PJ1, 완료 검수의 근거도 현재 판본에 결속해야 한다. 평가 지표와 실제 MCP 독립 효과는 DEV-46 및 별도 실기기 검수 범위다. 루트 검토에서 종료 코드 0에 실패나 미확인 건수가 섞일 수 있다는 결함과 10-15 배포 근거가 현재 점수로 섞일 위험을 발견해 각각 거부 조건과 점수 산출 차단 시험을 추가했다. 저장소 내 이 함수의 외부 Python 호출자는 검색에서 발견되지 않았고, 이전 명령을 적은 문서는 역사 기록으로 남겨뒀다.

# 대시보드 갱신과 대상 목록 일치

- 기준: `feat/console-ui`, 확인 커밋 `ba388908`. 기존 미커밋 화면 변경을 보존했다.
- 요청: 상단 및 최근 차단 갱신 누락, 실행 확인 200건 제한, 가입 대기 건수 누락, 최근 차단 기간 불일치의 네 가지를 수정한다.
- 갱신: 대시보드의 지표와 모드 및 상태, 가입과 활성화 및 도입 건수, 최근 차단 목록을 30초마다 해당 DOM 영역만 교체한다. 상세 및 확인창과 갱신 대상 포커스가 있으면 보류하며 화면 이동 시 요청을 중단하고 늦은 결과를 무시한다. 조회 실패는 기존 값과 경고로 표시하고 복구 시 경고를 지운다. 승인 검토와 성능 표 및 자원 갱신은 보존했다.
- 실행 확인: 기존 미해결 조건을 유지하며 전체 건수와 200건 단위 페이지 및 안정된 정렬을 제공한다. 처리 후 빈 마지막 페이지는 서버에서 보정한다. 상태 변경 API는 수정하지 않았다.
- 가입: 최근 신청 100건과 별개인 전체 대기 건수를 집계한다. 상태 필터와 100건 단위 페이지 및 페이지 보정을 제공한다. 대시보드에서 대기 목록으로 이동하고 사용자 관리에서 승인과 거부를 기존 방식으로 처리한다.
- 차단 기록: 최근 24시간의 도구 호출을 고정된 시작과 종료로 조회하고 같은 조건을 기록 링크에 전달한다. 미리보기는 그중 10건이다.
- 검증: 관련 JS와 번역 검사 8개 통과. 갱신, 모드 표시, 검토 보존, 늦은 응답, 실패 복구, 링크 기간과 유형, 가입 전체 건수 및 실행 확인 페이지와 버튼을 검사했다. 격리 SQL/API 검사 4개 통과. 최근 100건이 모두 처리됐어도 오래된 대기 150건을 집계하고 조회하는 경우, 305건의 미해결 호출을 중복 없이 조회하는 경우, 진행 중 예약과 해결된 호출 제외, 페이지 감소와 빈 목록, 직원 가입 조회 거부를 확인했다. JS와 Python 구문 검사 통과.
- 한계: SQL 시험은 PostgreSQL 매개변수 캐스트를 SQLite 문법으로 바꾼 격리 데이터이며 실제 PostgreSQL 검증이 아니다. 실제 배포와 브라우저 검수, 전체 회귀와 위키 검사는 미실행이다.
- 후속: 실행 PC에서 30초 갱신과 검토 보존, 실제 요청의 상태 변경 후 건수 및 페이지 일치, 최근 차단 링크와 조회 실패 및 복구를 검수한다. 커밋과 푸시는 하지 않았다.

# 승인 처리 이력을 대시보드로 이동

- 요청: 승인 처리 이력을 호출 승인과 같은 위치로 이동한다.
- 구현: `approvalWorkspace`에서 승인 대기 및 처리 이력 전환 링크를 제공한다. `setApprovalLists`에서 기존 API 이력을 보관하고 `approvalHistory`가 최근 50건과 기존 상세 조회 및 번복 버튼을 표시한다. 자동 및 수동 갱신은 선택한 보기를 보존하며 실패 시 기존 데이터를 유지한다.
- 호환: 기존 activity 승인 이력 및 approvals history 주소는 대시보드 호출 승인 탭의 처리 이력 보기로 연결한다. 호출 및 감사 기록에서는 이력 탭과 승인 API 조회를 제거한다. 개별 호출의 승인 정보와 관리자 인증, API 및 감사 원장은 변경하지 않는다.
- 검증: 이전 주소, 관리자 탭 구성, 대기 보기, 기존 검토 보존, 상세 및 번복 버튼 보존, 이력 갱신과 실패 데이터 보존 관련 UI 6개와 JS 구문 검사 통과. 전체 회귀와 위키 검사는 실행하지 않았다. 실제 배포와 브라우저 검수는 미실행이다.
- 작업 범위: 현재 콘솔 브랜치에서 기존 미커밋 변경을 보존했다. 커밋과 푸시는 수행하지 않았다.

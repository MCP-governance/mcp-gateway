# AI 연결 관리의 기능 위치 정리

- 요청: 공통 상단의 네 기능을 대상 탭으로 이동하고 CSV 및 JSON을 하나의 메뉴로 묶는다.
- 변경: MCP 서버 영역에 도구 정의 다시 확인과 도입 승인 등록부 내보내기를 배치했다. 내보내기는 기본 선택 상자에서 CSV 또는 JSON을 선택하며 기존 다운로드 동작을 호출한다. 처리 중 비활성화하고 성공과 실패 모두 선택을 초기화한다. 도입 신청 텍스트 바로가기는 제목 오른쪽에 유지했다. 커넥터 설정 내보내기는 기본 기능 및 커넥터 탭 상단에 배치했다.
- 경계: 서버 API와 내보내는 범위 및 내용, 점검 및 계약 승인 절차는 변경하지 않았다.
- 검증: 상단 기능 제거와 MCP 서버 동작 및 형식 선택 메뉴, 커넥터 탭 배치를 확인하는 기존 UI 검사 1개와 JS 구문 검사 통과. 실제 다운로드와 솔루션 배포 및 브라우저 검수는 미실행이다. 전체 회귀 및 위키 검사는 실행하지 않았다.
- Git: 현재 콘솔 브랜치의 기존 변경을 보존했으며 커밋과 푸시는 하지 않았다.

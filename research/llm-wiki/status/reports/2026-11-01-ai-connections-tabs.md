# AI 연결 관리 탭 통합

- 요청: 계약 탭을 서버 관리에 통합하고 벤더 커넥터 명칭을 보완한다. 첫 탭 명칭은 MCP 서버와 서버 목록 중 판단한다.
- 판단: MCP 외 연결을 함께 다루는 페이지이므로 MCP 서버가 대상을 더 명확히 구분한다.
- 구현: `ROUTES.servers`의 계약 전용 탭을 제거하고 MCP 서버 목록에 상태 사유 및 마지막 확인을 표시한다. 서버 상세에서 사유 전체와 확인 시각 및 기존 조건의 승인본 갱신을 유지한다. 상단 계약 다시 확인도 유지한다. 벤더 탭은 기본 기능 및 커넥터로 변경한다.
- 호환: `canonicalRoute`는 이전 계약 탭 주소를 MCP 서버 탭으로 보낸다. 사용자 검색 등 조회 조건과 서버 상세 식별자를 보존한다. API와 계약 승인 조건, 권한 및 차단 로직은 변경하지 않았다.
- 검증: 이전 주소와 관리자 탭 구성, 상태 및 확인 시각과 상세 승인본 갱신 보존 관련 UI 3개와 JS 구문 검사 통과. 실제 배포와 브라우저 검수는 미실행이다. 전체 회귀와 위키 검사는 실행하지 않았다.
- Git: 현재 콘솔 브랜치에서 작업했으며 커밋과 푸시는 하지 않았다.

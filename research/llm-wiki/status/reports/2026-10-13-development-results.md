## 실제 Claude 협업과 한계

WSL Claude CLI에 `claude-sonnet-5-5 --effort xhigh`를 지정했고 실제 주 모델 응답을 확인했습니다. `xhigh`는 요청 인자이며 서버 내부 effort 적용을 따로 증명하지 않았습니다. 첫 분석은 35턴 제한에 도달해 같은 네이티브 대화를 재개했고 최종 분석을 받았습니다. 분석은 소스 열람이며 실기기 시험 결과가 아닙니다.

후속 수정·재검토 CLI는 계정 세션 한도로 실패했습니다. CLI 안내는 당일 **17:50 KST 재설정**입니다. 다른 모델로 자동 대체하지 않았습니다. 수정·검증은 Codex가 이어서 수행했고 별도 Codex 검토자가 연결 코드와 회귀를 확인했습니다. Claude의 수정 후 리뷰는 완료하지 못했습니다. 기록기가 `<synthetic>` 실행 알림을 실제 모델 변경으로 오판했던 부분도 수정했으며, 과거 오류 기록은 지우지 않고 정정을 추가했습니다.

## 검증

로컬·격리 회귀 **63건**(자원 10, 표시/콘솔 상태 12, 카탈로그 4, 보안 경계 6, OAuth 7, field 17, 협업 콘솔 7)과 Rego **86건**이 통과했습니다. Python lint·JS 문법·무인증 API 목록·스키마 검사도 통과했습니다. 실제 기존 미커밋 파일을 제외한 Git index 추출본에서도 보안 경계·OAuth 회귀와 위키 검사가 통과했습니다. 제외된 기존 코드 관찰 3건은 정적 매핑 경고로 표시하며 변경했다고 숨기지 않습니다.

솔루션 기기의 실제 PostgreSQL에서도 [격리 통합 검사](../../../../full_stack_lab/tests/oauth_rotation_pg_check.py) **3건**이 통과했습니다: 동시 갱신 1건만 발급·계열 폐기, 발급 중 철회 직렬화, 실제 INSERT 제약 실패 시 회전·부분 발급 롤백. 서명 생성만 대체하고 SQL·DB 트랜잭션·advisory/row 잠금은 실제로 실행했습니다. UUID 스키마를 새로 생성하고 생성한 스키마만 제거했습니다. 제품 계정·기존 원장·테이블을 바꾸지 않았습니다.

구현 커밋은 `6178dd33afd36380578eb4327786300e51b954d9`, 통합 검사·기존 시험 기대 수정은 `c6ab26a4300fdcccd3c74a0905671394f250f478`입니다. [연구·협업 CI](https://github.com/MCP-governance/mcp-gateway/actions/runs/38351961556)가 통과했고, [최종 전체 CI](https://github.com/MCP-governance/mcp-gateway/actions/runs/38353250953)의 정적 검사·완료 조건 전체 검증이 모두 통과했습니다. [첫 전체 CI 실패](https://github.com/MCP-governance/mcp-gateway/actions/runs/38351961592)는 오래된 관리형 거부 문구 단언에서 발생했고 수정 후 재검증했습니다.

## 솔루션 기기 배포·측정

지정 솔루션 기기에서 `full_stack_lab/console.sh field up`으로 구현 커밋을 배포했습니다. 초기 Docker 빌드는 누락된 `docker-credential-desktop.exe` 때문에 실패했고, 원래 Docker 설정을 보존한 채 공개 이미지용 임시 DOCKER_CONFIG로 재시도해 완료했습니다. 기존 엔드포인트 수정 3파일은 배포 전후 SHA-256이 동일합니다. 계정·원장·볼륨·승인 계약을 초기화하지 않았습니다.

Gateway와 Console은 모두 revision `6178dd3`, code SHA-256 `11a28d7660bae72b5662c0590a94ec1050659e987aa66adb29325c47eacbb1a6`입니다. `/api/readiness`는 ready, build consistent=true, 실제 로드된 OPA 규칙·데이터 hash matches=true를 확인했습니다. 이후 테스트·문서 커밋은 runtime 코드를 바꾸지 않으며 이 보고의 실행 이미지 근거는 구현 커밋입니다.

14:48:46 KST 표본은 CPU **1.49%**(6.081초 간격), 메모리 **14.63%**(total 11,921,043,456 bytes / used 1,744,371,712 bytes), 내부 연결 **1.25ms**입니다. 호스트 `free -b`의 총 메모리와 일치했습니다. 미인증·직원 Console 토큰·관리자 역할의 MCP scope 토큰은 지표 조회가 거부되고 관리자 Console 토큰만 허용됐습니다. 시험 발급한 OAuth 계열은 즉시 철회했습니다.

수치는 컨테이너의 `/proc`에서 보이는 **Linux 호스트/VM** 범위입니다. 물리 Windows 전체·개별 컨테이너 quota를 의미하지 않습니다. 지연은 Console→Gateway DNS·TCP 연결 시간이며 PC→솔루션 Tailnet 지연·패킷 손실률과 다릅니다.

Chrome 제품 현황에서 CPU·메모리·내부 연결 지연의 실제 표시·갱신을 확인했습니다. Codex 내장 브라우저는 로그인 후 `/auth/me`가 401로 돌아오는 현상을 보여 Chrome과 대조했습니다. Chrome에서는 정상 로그인·표시가 됐습니다. Chrome 캡처 도구가 시간 초과되어 제품 raster 캡처는 확보하지 못했으며, DOM 확인과 실기기 API 결과를 근거로 합니다. 협업 콘솔은 내장 브라우저 화면을 확인·캡처했습니다.

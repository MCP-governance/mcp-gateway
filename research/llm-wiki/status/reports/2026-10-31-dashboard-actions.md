# 대시보드 조치 필요 구성

- 기준: `feat/console-ui`, 시작 커밋 `56ace776`. 앞선 호출 통계 작업의 미커밋 변경을 보존하고 이어서 수정했다.
- 요청: 상단에 현재 조치 필요를 우선 배치하고 오늘 도구 호출에는 전체와 차단만 표시한다.
- 구현: 상단 네 항목은 실행 확인 필요, 통제 점검 필요 연결, MCP 점검 필요, 종료 조치 필요다. 실행 보조 수치와 현재 상태 영역을 제거했다. 요약 탭에는 승인과 가입 및 활성화, 도입 조치를 유지하고 상단과 중복된 건수는 제거했다.
- 경계: 연결 점검은 기존 우회 가능 분류이며 실제 공격 발생을 뜻하지 않는다. MCP는 연결 오류, 계약 변경, 확인 대기만 집계한다. 종료는 진행 중과 종결 대기를 포함한 모든 미종결 케이스다. 종료 판정 기준과 실행 처리, 인증은 변경하지 않았다.
- 목록: MCP 점검 필터를 추가했다. 종료 목록 API는 미종결 및 기한 초과 필터를 DB에서 적용한 뒤 안정된 순서로 50건씩 조회한다. 페이지 이동으로 50건 이후 대상도 확인한다. 집계는 목록 제한을 적용하지 않는다.
- 검증: JS와 Python 구문 검사 통과. 대시보드, MCP 필터, 종료 필터와 페이지 링크 및 번역 검사 6개 통과. 종료 집계와 SQL 조건을 SQLite 격리 데이터로 검사한 3개 시험 통과. 등급 없는 진행 케이스와 종결 대기, 이미 종결된 케이스, 기한 경계, 60건 분할과 중복 여부를 확인했다. PostgreSQL 전용 캐스트와 시간 함수는 시험에서 SQLite 표현으로 변환했다.
- 한계: 실제 PostgreSQL과 브라우저 연동, 솔루션 배포는 미실행이다. 사용자 지시에 따라 위키 검사와 전체 회귀 검사는 실행하지 않았다.
- 후속: 실행 PC에서 상단 배치와 화면 크기별 줄바꿈, 네 지표의 대상 목록 일치, 종료 필터와 페이지 이동을 검수한다. 커밋과 푸시는 하지 않았다.

## 요약 탭 후속 정리

- 승인 및 등록, 호출 승인 요청, 최근 차단 10건, 시스템 자원 순서로 변경했다. 승인 및 등록에는 가입 승인과 엔드포인트 활성화 및 도입 조치만 남겼다. 중복된 호출 승인 건수 링크는 제거하고 기존 요청 목록과 전체 보기는 유지했다.
- 데이터 조회 및 승인 처리와 시스템 자원 갱신 동작은 변경하지 않았다. 단순 표시 변경으로 JS 구문 검사만 수행하고 추가 테스트와 위키 검사는 실행하지 않았다. 실제 화면 검수는 미실행이다.

# 대시보드 호출 통계 정리

- 기준: `feat/console-ui`, 시작 커밋 `56ace776`.
- 요청: 전체 호출과 차단된 호출을 강조하고 실행된 호출은 보조 수치로 둔다. 실행 미확인은 현재 미해결 건수로 관리자 조치에 표시한다.
- 구현: 오늘 운영 현황을 오늘 도구 호출로 변경했다. 두 주요 카드와 실행 보조 링크를 구성했다. 기존 관리자 overview API에 `unresolved_execution`을 추가하고 기존 `dispatch.uncertain_count()`를 사용한다. 실행 확인 목록과 같은 조건이며 오늘과 200건 목록 제한의 영향을 받지 않는다.
- 검증: JS 구문 검사와 대시보드 및 번역 검사 4개 통과. 화면 시험에서는 오늘 미확인 2건과 현재 미해결 305건을 구분했다. 데이터베이스 통합 시험과 실제 배포 및 브라우저 검수는 미실행이다. 위키 검사와 전체 회귀는 생략했다.
- 후속: 실행 PC에서 카드 배치와 호출 로그 필터, 이전 날짜의 미해결 호출 표시 및 실행 확인 후 감소를 확인한다.
- Git: 커밋과 푸시하지 않았다.

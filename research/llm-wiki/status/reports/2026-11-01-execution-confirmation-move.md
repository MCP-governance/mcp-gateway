# 실행 결과 확인을 대시보드로 이동

- 요청: 관리자 처리 위치를 대시보드로 모으고 호출 및 감사 기록의 실행 확인 탭을 제거한다.
- 구현: `executionConfirmationTab`을 분리해 대시보드의 호출 승인 다음에 실행 결과 확인을 제공한다. 승인 처리 이력은 기존 기록 페이지에 유지하며 해당 페이지는 미해결 호출 목록을 조회하지 않는다.
- 호환: 대시보드의 실행 여부 확인 지표와 이전 실행 확인 주소는 대시보드 전용 탭으로 연결한다. 페이지 조건과 200건 단위 조회, 전체 미해결 건수와 결과 기록 버튼 및 확인 내용 입력을 유지한다. 관리자 인증 및 미해결 판정과 중복 실행 방지 로직은 변경하지 않는다. 개별 호출의 결과와 연관 기록 조회도 유지한다.
- 검증: 기존 주소, 관리자 탭 구성, 대시보드 이동, 200건 이후 페이지 및 결과 기록 버튼과 승인 번복 보존 관련 UI 검사 5개와 JS 구문 검사 통과. 전체 회귀 및 위키 검사는 실행하지 않았다. 실제 배포와 브라우저 검수는 미실행이다.
- 작업 범위: 현재 콘솔 브랜치의 기존 변경을 보존했다. 커밋과 푸시는 수행하지 않았다.

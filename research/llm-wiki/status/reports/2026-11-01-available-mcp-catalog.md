# 사용 가능한 MCP의 탐색과 이용 방법

- 요청: 승인된 MCP의 제목과 목록 및 상세, 제공 도구와 이용 방법 및 검색을 개선한다.
- 구현: 내부 approved 키와 API 주소는 유지하며 화면 명칭을 사용 가능한 MCP로 변경했다. 목록에 이름, 사용 목적, 도구 수와 사용 기한 및 이용 방법을 제공한다. 이름과 사용 목적 및 도구 이름과 심사 목적을 검색한다. 검색어는 재조회 시 유지하고 검색 포커스 및 상세 검토 중에는 자동 교체를 보류한다. 빈 목록은 새 신청으로 연결한다.
- 상세: 이용 방법에 현재 콘솔 출처의 게이트웨이 주소와 복사, 실행 방식 및 계정과 키트 설정 진입을 제공한다. 도구 상세는 승인 행위와 목적 및 범위 심사 상태를 표시한다. 출처와 고정 커밋 및 기존 소스 다운로드는 출처 탭에 둔다. UI에 임의 실행 명령이나 자격을 만들지 않는다.
- API: 기존 approved_mcp_rows의 권한과 서버 및 승인 상태, 기한과 출처 검증을 유지한다. 신청 목적과 등록 승인 도구에서 필요한 공개 정보만 투영한다. 도구의 원본 인자 제약과 내부 자격은 반환하지 않는다. 상세 열기 및 주소 복사 시 현재 목록을 다시 확인해 철회 후 이전 주소를 복사하지 않는다. 기존 다운로드의 권한과 고정 커밋 검증은 변경하지 않았다.
- 검증: 관련 UI 5개와 번역 검사 1개, 격리 API 및 권한 검사 3개와 JS 및 Python 구문 검사 통과. 노출 필드와 직원 범위, 원격 서비스와 다운로드 구분 및 안전한 이스케이프, 검색과 빈 목록, 상세 이동과 재조회 후 복사 차단을 확인했다. 실제 서버 연결 및 소스 다운로드와 배포 및 브라우저 검수는 미실행이다. 전체 회귀와 위키 검사는 실행하지 않았다.
- Git: 현재 콘솔 브랜치에서 기존 변경을 보존했으며 커밋과 푸시는 하지 않았다.

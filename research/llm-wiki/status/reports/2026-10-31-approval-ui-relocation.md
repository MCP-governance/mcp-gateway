# 승인 작업 화면 재배치

- 기준: `feat/console-ui`, 시작 커밋 `66751a7a`.
- 요청: 호출 승인은 대시보드, 실행 확인과 승인 처리 이력은 호출 및 감사 기록, 개인 이용 동의는 내 계정으로 옮기고 승인 대기 메뉴를 제거한다. 커밋과 푸시는 하지 않는다.
- 구현: `console.js`의 대시보드에 최대 5건 미리보기와 전체 호출 승인 탭을 두고 가입 승인과 활성화 작업으로 연결한다. 실행 확인과 처리 이력은 관리자 호출 기록 탭에 배치한다. `agent_service.py`의 관리자 허용 페이지에서 approvals를 제거하고 consent를 추가한다. 이용 동의 API는 기존 본인 범위를 유지한다.
- 보존: 기존 증빙 확인과 승인 및 거부, 본인 요청 제한, 승인 번복과 실행 확인 동작. 신규 API나 권한 완화는 없다.
- 검증: JS 구문 검사 통과. `console-ia`, `i18n`, `high-impact-console`, `high-impact-evidence-console`의 테스트 30개 통과. 기존 정책 제목 배치에 맞지 않던 테스트 기대값과 새 번역 키를 보정했다.
- 한계: 솔루션 배포와 브라우저 검수는 미실행이다. 실제 승인 및 실행 확인 요청을 서버에 전송하는 통합 시험은 수행하지 않았다. 사용자 지시에 따라 위키 생성과 전체 회귀 검사는 생략했다.
- 후속: 실행 PC에서 관리자 대시보드, 감사 기록의 실행 확인과 승인 번복, 관리자 및 직원의 개인 이용 동의를 검수한다.

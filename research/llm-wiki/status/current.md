# 개발 현황 — 2026-10-23

이 문서는 지금 상태만 담는다. 지난 서술은 [이력 목차](history/README.md)로 옮겨 보존했다(내용 변경 없음). 진척률·상태·담당의 정본은 구글 [MINT 개발 통합 시트](https://docs.google.com/spreadsheets/d/1bfD-wfPn_ldwB-AV2o1RAr6DbAtLnQV6JJQd-exJpLI/edit)의 「WBS」·「백로그」 탭이다.

- Windows 원클릭(W11, D-197): 한 파일·UAC 1회 설치를 main에 병합. Codex 독립 검토는 코드 결함 없음, 실제 Windows 설치·UAC·활성화는 pj3 접속 불가로 미실행([보고](reports/2026-10-23-windows-oneclick.md)).
- 발표용 경쟁·갭 매트릭스(RES-GAP): [10개 기능·9개 제품](../analysis/gap-matrix-1023/README.md)의 구현·배포·실측 270개 단계를 분리했다. MINT는 코드·DECISIONS·지정 10-23 실사용 보고만 사용하며 엔드포인트 우회 차단·종료 효과·AI 게이트웨이 연동 실측은 미확인이다. 문서 종합이며 새 제품 시험은 하지 않았다. 검증·검토 인계는 [보고](reports/2026-10-23-gap-matrix.md) 참조.

## 한눈에 보기

**수치** WBS 57개 작업의 다섯 단계 가중 진척 63.3%, 최종 검수 완료 0개, 구현 완료(검수 전) 56개·일부 구현 1개, 실제 환경 단계는 57개 중 21.5개 상당이다(시트 WBS 57행을 10-23에 직접 읽은 값이며 협업 웹 `/api/wbs`와 일치). 10-21 이후 이미 완료인 구현·회귀에는 점수를 다시 주지 않았다.

**되는 것** — main에 병합돼 있고 기기 배포와 실제 호출 기록이 있다.
- 직원 PC 키트: Linux(PJ1)는 설치 → 관리자 활성화 → Claude로 github·markitdown 호출 Allow까지, Windows(pj3)는 설치 → 활성화 → 트레이 연결까지 확인했다([DEV-84](reports/2026-10-22-kit-e2e.md)).
- 로컬 MCP 원클릭 승인(D-192): 이미지 이름만 넣어 digest로 고정하고, PJ1 Claude가 호출해 동의 전 Block → 동의 후 Allow가 원장에 남았다([DEV-83](reports/2026-10-22-local-mcp-oneclick.md)).
- 회원가입 수정(재신청·승인 전 안내·대문자 아이디·접속 주소별 제한)과 PR #36 병합·배포(CI 전 단계 통과)([DEV-82·85](backlog.md)).
- LiteLLM 등 AI 게이트웨이 애드온(D-191): 업스트림 방식과 호출 직전 판정 API가 배포돼 있다. 승인 계정이 없어 실제 MINT 연동 시험은 아직이다([AIG-01](reports/2026-10-22-ai-gateway-addon.md)).
- 10-21 기능 묶음(한 화면 도입 승인, 위험 등급 승인, root 단독 운영, 자동 중지, SBOM 영향 조회, 되돌리기, 직원별 중지, 오프라인 버퍼)은 main에 병합돼 있으나 대부분 대역 시험까지다([10-21 정리](history/2026-10-21-to-23.md)).

**안 되는 것·확인하지 않은 것**
- macOS 키트 실설치([DEV-87](reports/2026-10-22-kit-macos.md))는 맥북이 필요해 미실행이다. Windows·Codex 하네스의 모델 호출은 로그인이 필요해, UAC 화면은 보안 데스크톱이라 미실행이다.
- LiteLLM 승인·철회 동기화(D-208)는 `10/23-litellm-sync`에서 선택 애드온으로 구현했고 HTTP 대역 21건·기존 운영23/SBOM8·화면 상태15/UI6 검사를 통과했다. 기존 애드온 회귀는 의존성 미설치로 실행 불가이며 LiteLLM 1.105·PostgreSQL·PJ1 실기기 검증은 미실행이다([보고](reports/2026-10-23-litellm-sync.md)). 저장소 하위 경로 신청(DEV-88)은 시험·기기 확인 기록이 없다.
- 실제 PostgreSQL 경합과 PJ1 확인이 보고서에 미실행으로 남은 항목은 DEV-73~80·OPS-01이다(백로그 「남음」 참조).
- DEV-81은 열려 있다. 같은 UID/SID의 다른 프로세스가 헤더 소켓·파이프의 bearer를 얻을 수 있고, Linux는 AppArmor 경고 단계이며 직원 PC 키트는 막지 못한다고 명시했다.

**진행 중(main 밖)** Windows 직원 단독 원클릭(W11)은 Codex 작업으로 투입됐다는 리더 기록(10-23 01:00)만 있고 저장소 원격에는 아직 브랜치가 없다.

**읽는 법** 「구현 완료(검수 전)」는 검수 끝이 아니다. 대역·단위 시험 통과는 실제 PostgreSQL·기기·PJ1 확인이 아니며, 과거 보고서는 현재 배포 증거가 아니다. 이 구분은 [작업 규칙](../AGENTS.md)을 따른다.

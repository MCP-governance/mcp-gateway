# GensOps — 젠아이랩스 전사 운영 관제 플랫폼 확인

확인일: 2026-10-23 · 확인 수준: 공급자 제품 페이지·사례 글·라이브 데모 첫 화면 읽기 · 제품 시험·코드 없음(코드 미공개).

## 대상 특정

"GensOps 운영 관제 플랫폼"은 젠아이랩스(GenAI Labs)의 제품 [GensOps](https://gensapps.com/gensops)(「전사 운영 관제 플랫폼」)로 특정한다(G2). 제품 목록에서 ACT(실행) 계열의 「운영 관제」로 분류되고, 사례 글의 「사례 둘: GensOps」가 같은 제품이다(G3). 표준 검색의 「GenOps」(Google 등의 일반 개념, GenOps.ai·Eviden 제품)는 철자만 비슷한 다른 대상이라 제외했다.

## 제품이 말하는 것(요약)

- 상태: 2026-10 기준 v1.8.0, 젠아이랩스 사내 운영 중. 외부 가입은 열지 않았고 가상 회사 데이터로 만든 로그인 없는 데모만 공개한다(데모 첫 화면 확인: 「데모·가상 데이터」 표시, 2D·3D 전환, 서버·git·서비스·비용 패널).
- 수집: 서버의 에이전트와 CI가 상태·테스트 결과를 보낸다.
- 화면: 서버·컨테이너·서비스 상태와 가동률(확인 필요 항목을 맨 위로), 전사 git 흐름·CI/CD 실행 이력·프로젝트별 테스트 수와 시간, 클라우드·AI 모델 비용과 예산, AI 코딩 세션 현황, 조직 규칙 문서·스킬 검색. 같은 데이터를 2D 관제실과 3D 관제실로 본다(대형 화면 상시 표시 용도).
- 조치: 재시작 같은 조치는 「제안 → 승인 → 실행 → 기록」 순서로만 진행하며 사람이 승인해야 실행되고 전부 기록된다.
- 개발: 사례 글은 설계에서 운영 배포까지 8일, 저장소 43개의 30일 커밋·머지·태그를 한 시간축에 표시한다고 쓴다(회사 자체 기록).

## 미확인

- 실제 운영 화면과 데이터는 비공개다(데모는 가상 데이터). 지표 수집 방식, 알림 규칙, 승인자 모델, 기록의 변조 방지 여부는 공개 자료에 없다.
- 「승인 뒤에만 조치」 흐름이 코드에서 강제되는지는 확인하지 못했다. 제품 설명이다.
- 수치(가동률·테스트 수 등)는 모두 회사 자체 기록이며 외부 검증이 없다.

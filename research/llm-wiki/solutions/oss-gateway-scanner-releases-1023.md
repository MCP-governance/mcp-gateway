# OSS 게이트웨이·스캐너 최신 릴리스와 공시 (2026-08~10)

확인일: 2026-10-23 · 확인 수준: GitHub 릴리스 노트·저장소 메타데이터·보안 권고(공개 API 응답)와 공급자 공식 글 선택 열람. **코드를 읽거나 설치·실행하지 않았다.** 기능은 릴리스 노트가 밝힌 범위이며 활성·성능·우회 여부는 미확인이다. [출처 manifest](../analysis/refs-update-1023/refs-update-1023.sources.json)에 URL·확보 시각·SHA-256이 있다.

## 이 카드가 말하지 않는 것

- 각 제품이 실제로 호출 단위 인가를 하는지, 기본값이 안전한지, 설치가 되는지는 확인하지 않았다.
- 권고의 영향 판본·수정 판본은 권고 문서의 표기를 옮긴 것이며 수정 코드는 읽지 않았다.
- Snyk Agent Scan의 토큰 요구·stdio 서버 실행 설명은 2차 자료이므로 사용 전에 공식 문서로 확인한다.

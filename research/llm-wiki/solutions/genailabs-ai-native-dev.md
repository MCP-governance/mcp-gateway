# 젠아이랩스(GenAI Labs) — AI-native 개발 사례 확인

확인일: 2026-10-23 · 확인 수준: 회사 공식 사례 글·제품 페이지 읽기 · 수치는 회사 자체 기록 · 코드 미공개.

## 대상 특정

"젠아이랩스"는 서울 강남구에 소재한 생성형 AI 스타트업 젠아이랩스(GenAI Labs)다. 공식 홈 [genailabs.kr](https://genailabs.kr/)과 제품 포털 [gensapps.com](https://gensapps.com/)이 같은 회사를 가리키며, 포털 하단에 상호·소재지가 있다(G1·G2). 사용자가 말한 「AI-native 개발 사례」는 공식 사례 연구 [AI-native 회사가 일하는 방법](https://gensapps.com/case-studies/ai-native-company)(2026-10-01 작성, 10-08 수정)으로 특정한다(G3). 표준 검색으로는 회사명이 나오지 않았고 확장 검색에서 공식 사이트를 찾았다. 이름이 비슷한 다른 회사일 가능성은 사례 글이 GensOps와 같은 사이트·같은 회사 소개를 쓰는 점으로 낮다고 본다.

## 사례 글 요약(회사 주장)

- 대상: 2026-03부터 운영 중. 저장소 40여 개, 제품 10여 종. AI 코딩 에이전트(Claude Code) 여러 세션을 병렬로 쓴다.
- 구조: 사람은 방향·승인, AI는 실행, 기계(자동 검사)는 확인. 운영 영향 변경·되돌릴 수 없는 삭제·비용이 드는 일은 사람이 결정한다.
- 공용 규약 저장소(문서 40여 개)와 시작 템플릿, 표준 CI/CD, 비밀값 검사(PR마다·주 1회 전체 이력), 준수 현황표를 규칙(약속)과 현황(사실)으로 나눠 둔다.
- 배포 성공 판정: 헬스 응답에 방금 배포한 커밋이 있어야 성공으로 본다. 운영 서버에는 소스 코드를 두지 않는다.
- 실수 기록: AI 작업 기록에서 스스로 잘못을 인정한 600여 건을 전수 조사해 원인별로 묶고, 문서 규칙 추가로는 반복이 줄지 않아 「막힌 순간에 할 일 11줄」·자동 검사·시험으로 바꿨다고 한다. 「틀린 가설 기록」(가설·근거·반증·수정·교훈)을 둔다.
- 시험: 자동 테스트 약 19,800개, 2026-09 자동 검사 중 310건 차단, 건너뛴 검사는 통과가 아니라 실패, 「검사 대상 0개」 통과를 의심한다.
- 협업: 선택지는 비용·시간·위험을 먼저 적고, 「확인했다」 대신 무엇을 어떻게 봤는지 적는다. AI 세션끼리 서로 검토한다.
- 한계(회사 서술): 「하지 않은 확인을 했다고 말하는」 유형은 규칙·검사로 줄지 않아 최종 확인은 사람이 맡는다. 수치는 자체 기록이며 외부 검증이 없다.

체감 생산성 「100배」 등 효과 문구는 마케팅 표현으로 사실로 옮기지 않는다. 이 문서의 모든 수치는 「회사 자체 기록」이다.

## 관련 제품(같은 회사)

- [GensOps](genailabs-gensops.md): 전사 운영 관제 플랫폼.
- GuardTrail([소개](https://gensapps.com/guardtrail), G4): 셸 명령·파일 접근·메일 발송·MCP 도구 호출을 실행 직전에 판정하는 Agent XDR(페이지 제목은 Agent EDR 표기도 있음). Claude Code에는 PreToolUse 훅, MCP 서버에는 stdio shim으로 붙인다. 판정은 LLM 없이 점수로 하며, 처음 2주는 관찰만 한 뒤 검토한 정책을 차단으로 켜라고 권한다. 같은 페이지에 자사 개발 환경 한 곳(Claude Code 세션 1,068개, 도구 호출 75,430건)에서 93.8%가 MCP를 거치지 않는 내장 도구였다는 측정이 있다. 한 환경의 자체 측정이며 일반화하지 않는다.
- GenAI Shield: 개인정보를 가리는 AI 게이트웨이(소개 문장만 확인, 상세 페이지는 이번에 읽지 않음).

## 코드 공개 여부

공식 사이트에서 GitHub 저장소 링크를 찾지 못했다. `github.com/genailabs` 조직은 2023-05 생성, 공개 저장소 0개(API, 2026-10-23)이며 회사와의 소유 관계는 확인하지 못했다. 따라서 **코드 미공개**로 두고 사례 조사만 한다.

# BeyondTrust Pathfinder MCP — 상용 문서 확인

확인일: 2026-10-13 · 확인 수준: 공급자 공식 문서 · 코드·제품 시험 미실시.

[공식 설정 문서](https://docs.beyondtrust.com/bt-docs/docs/configure-pathfinder-mcp)는 미국 지역 Early Access, 사이트별 관리자 활성화, Read Only 모드, 사용자별 토큰 발급을 설명한다. 토큰 기간은 30·60·90일 또는 최대 1년 사용자 지정이며, 활성 토큰 회수와 만료 토큰 삭제를 구분한다. 사이트 기능을 Off로 바꾸면 기존 토큰의 연결도 중단된다고 명시한다.

이 페이지는 Entitle을 포함한 여러 BeyondTrust 제품의 최소 버전·별도 설정 요건도 표시한다. 따라서 Pathfinder MCP가 임의의 모든 외부 MCP를 통제하는 일반 gateway라는 가정으로 비교하면 안 된다. 제품별 기존 권한과 라이선스 조건을 확인해야 한다.

우리 개발에 참고할 것은 사용 기한·회수 상태·사이트 활성화 상태의 분리다. 종료 판정에서 token 목록의 Delete를 실제 권한 회수 증거로 그대로 쓰지 않는다. 회수 응답과 회수 후 접근 실패·설정 잔존을 함께 확인하는 실험으로 연결한다.

코드·토큰 회수 전파 시간·승인 절차·자격의 저장 방식·국내 처리 위치·인증은 확인하지 않았다. 일반 제품의 JIT 기능을 읽기 전용 Pathfinder MCP의 매 호출 승인 기능으로 확대하지 않는다. 문서 전체 대신 링크와 자체 요약을 보관한다.

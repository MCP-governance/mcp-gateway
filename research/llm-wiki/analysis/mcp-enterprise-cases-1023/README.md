## 4. 사례를 읽는 한계와 미확인

- 국내 사례는 기술 블로그 RSS 최근 항목(토스·우아한형제들·네이버 D2·라인·당근·올리브영·쿠팡 등 14곳 조회)에서 MCP를 다룬 글을 찾아 읽었다. 같은 조회에서 우아한형제들·네이버·당근·쿠팡에는 사례로 쓸 만한 MCP 도입 글이 없었다(네이버 D2의 2026-10-01 글은 개념 정리). 카카오뱅크·카카오·NHN·삼성SDS·SK텔레콤은 해당 사례를 찾지 못했다.
- 한국 금융권 사례는 보도된 강연(KB데이타시스템) 하나뿐이며 은행·보험사의 실제 도입 구조는 확인하지 못했다. 금융보안원 지침 여부도 확인하지 못했다.
- Booking.com·Salesforce·Hitachi·Bloomberg 등 AGNTCon+MCPCon 유럽(2026-09)의 발표는 제목·초록만 있고 본문·발표 자료를 읽지 못했다. Booking.com만 초록을 읽어 표에 넣었다.
- Pinterest·Uber는 자동 요청이 막혀(403·406) 브라우저 창에서 전문을 읽었다. 원본 HTML 파일은 보관하지 못하고 같은 URL의 응답 바이트 해시만 계산했다(manifest의 `local_path` 비어 있음 표시).
- 사례의 규모·효과 수치는 모두 자기 보고다. 회사별 도입 효과의 비교는 하지 않았다.
- Cloudflare 글은 자사 제품을 파는 글을 겸한다. Cisco·Snowflake·Microsoft 같은 공급자의 기업 도입 사례는 이번에 별도로 조사하지 않았다.
